# FireWatch 모바일 — Play 스토어 제출 가이드

코드로 처리할 수 있는 건(개인정보 이용 동의 화면, 계정 삭제, 개인정보처리방침)은 이미 끝났다 ([[llm-wiki/log]] 2026-10-06).
남은 건 Play Console 양식 작성·실기기 검증처럼 **사용자만 할 수 있는 단계**다 — 아래는 그걸 틀리지 않게 채우기 위한 참고 자료다.
법 자문이 아니라 실제 코드(`UserSettings`/`AppUser`/`DeviceLink` 엔티티, `AuditLogAspect`)를 근거로 작성한 초안이므로, 제출 전 한 번 검토할 것.

## 1. Data Safety(데이터 보안) 양식

Play Console → 앱 콘텐츠 → 데이터 보안. 아래는 실제로 수집하는 항목만 근거로 작성했다 — "수집하지 않음"이라고 적은 항목은 코드에 없는 걸 확인한 것이다.

| Play 카테고리 | 수집 여부 | 세부 | 목적 | 제3자 공유 |
|---|---|---|---|---|
| 기기 또는 기타 ID | O | 앱이 생성한 익명 기기 식별자(`X-Device-Id`), 푸시 토큰(FCM) | 앱 기능(설정 저장, 알림 발송) | 아님(Expo Push Service가 발송 중계는 하지만 FireWatch가 "판매·광고 목적으로 공유"하는 게 아님) |
| 개인 정보 > 이메일 주소 | O(선택) | Google 계정 연동 시에만 — 이메일 | 계정 관리(기기 간 설정 동기화) | 아님(Google 로그인 자체가 Google과의 거래이지 FireWatch가 제3자에 넘기는 게 아님) |
| 개인 정보 > 사용자 ID | O(선택) | Google 계정 고유 식별자(sub) | 계정 관리 | 아님 |
| 위치 | 수집 안 함 | — | — | — |
| 금융 정보 | 수집 안 함 | 관심 종목 티커(005930.KS 등)는 "보유 계좌·결제 정보"가 아니라 사용자가 고른 공개 종목 코드 목록이라 Play가 정의하는 금융 정보(계좌·거래내역 등)에 해당하지 않는다고 판단 — 다만 보수적으로 가고 싶으면 "앱 활동 > 기타 사용자 생성 콘텐츠"로 신고해도 무방 | — | — |
| 메시지 | 수집 안 함 | 사용자 간 메시지 기능 없음 | — | — |
| 사진/동영상/오디오/파일 | 수집 안 함 | — | — | — |
| 앱 활동 | 수집 안 함 | 사용 패턴 추적(애널리틱스)을 하지 않음 — 감사 로그는 운영자(개발자) 전용 내부 기록이지 이용자 프로파일링이 아님 | — | — |
| 앱 정보 및 성능 | 수집 안 함(크래시 리포팅 SDK 없음) | — | — | — |

공통 체크박스:
- **광고를 포함하는가** → 아니오(광고 SDK 자체가 없음 — `package.json`에 AdMob 등 미설치 확인).
- **데이터가 암호화되어 전송되는가** → 예(HTTPS만 사용).
- **삭제를 요청할 방법을 제공하는가** → 예 — 아래 "삭제 URL"에 `https://firewatch-eqp.pages.dev/privacy`(계정·데이터 삭제 섹션) 입력.
- **모든 수집이 선택인가** → 기기 식별자·푸시 토큰은 필수(알림 기능 자체가 이걸 전제로 함), Google 계정 연동은 선택.

## 2. 금융 기능(Financial Features) 선언

Play Console → 정책 → 앱 콘텐츠 → 금융 기능. "대출/투자/암호화폐/결제" 등 실제 금융 서비스를 제공하는지 묻는다.

FireWatch는:
- 가상투자 게임(`/game`)은 **실제 돈이 전혀 오가지 않는 가상 시뮬레이션**이고, 실제 증권사 계좌 연동·실거래·실입출금 기능이 없다.
- 시세·브리핑은 **공개된 시장 데이터를 보여주는 정보 제공**이지 투자 자문이 아니다(`GeminiClient` 프롬프트에도 "실시간 시세 조회 없이 일반적인 상관관계 수준의 참고용 추천"이라고 명시).

**권장**: 모든 금융 서비스 항목에 "아니오"로 답하는 게 맞다고 판단된다 — 다만 이건 Play 정책의 최종 해석 문제라 제출 전 질문 문구를 직접 한 번 더 확인할 것.

## 3. 콘텐츠 등급(Content Rating) 설문

- 폭력·선정성·도박 콘텐츠 없음.
- 가상투자 게임은 **실제 화폐가 아닌 가상 포인트**로만 동작 — "실제 도박/베팅" 관련 질문에는 해당 없음으로 답하면 된다.
- 예상 등급: 전체 이용가(또는 3+/Everyone).

## 4. 남은 실행 단계 (실기기 필요 — 세션이 대신 못 함)

1. `.env`에 `EXPO_PUBLIC_GOOGLE_ANDROID_CLIENT_ID` 값 채우기(BE-12에서 이미 발급된 값, Google Cloud Console에서 확인 — 비밀 아님).
2. `eas build --profile development --platform android`로 dev client APK 빌드·설치.
3. 실기기에서 아래 전부 왕복 확인:
   - 최초 실행 시 개인정보 이용 동의 화면(APP-11)
   - 푸시 알림 수신(APP-2)
   - 브리핑 상세·바텀시트(APP-3)
   - 설정 화면 저장(APP-4)
   - Google 로그인 연동 → 재실행해도 연동 상태 유지되는지(2026-10-06에 고친 버그)
   - 설정 화면의 "계정 삭제" 버튼(2026-10-06 신규)
4. 문제없으면 `eas build --profile production --platform android`로 실제 제출용 AAB 빌드(`eas.json`에 이미 production 프로필 있음, Android 기본 출력이 AAB라 추가 설정 불필요).
5. Play Console에서 새 앱 등록 → 위 1~3번 양식 작성 → 비공개 테스트(internal testing) 트랙에 AAB 업로드 → 테스터로 본인 등록 후 다시 한번 실기기 확인 → 문제없으면 프로덕션 출시로 전환.
