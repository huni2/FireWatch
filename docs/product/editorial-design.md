# FireWatch 전체 화면 디자인 정리

2026-10-11 사용자 디자인 리뷰 반영. 기존 WEB-38/Issue #62에서 기록하며 새 과제를 파생하지 않는다.

## 화면의 우선순위

- PC는 한 줄 헤더와 읽기 폭 1,280px을 사용한다. 게임 작업 공간은 최대 1,440px이며 고정 주문 영역을 유지한다.
- 좁은 웹과 Android의 주요 이동은 하단에 둔다. 웹 게임의 다음 주 버튼은 하단 메뉴 위에 위치한다. Android는 안전 영역을 포함한다.
- 카드·테두리·주황색 강조를 반복하지 않는다. 자산·기업·뉴스는 목록으로 읽고, 중요한 발견·주문·연결 지도에 독립된 표면을 사용한다.
- 금액과 단위, 확인된 시세 기준을 가까이 표시한다. 기본 라이트·저장된 다크 선택, 터치 영역, 키보드 초점을 유지한다.
- 헤더에서는 작은 크기에 읽히는 불꽃 SVG를 사용한다. 기존 커스텀 아이콘과 게임 시작/회고 캐릭터는 유지한다.

## 내 기록과 등록

평가액 → 핵심 발견 → 보유 자산 순서로 압축한다. 모바일 첫 화면에 첫 보유 항목이 보이도록 중복 제목·설명을 줄인다. 빈 화면에서는 두 ETF의 같은 지수 연결을 가상 예시로 보여주고 첫 자산 등록을 안내한다. 평균 매입가는 선택이며 등록/수정/취소와 서버 저장 오류·기록 보존은 기존 계약을 유지한다.

새 `내 투자 연결 지도`는 등록된 분야·거래 통화·ETF 지수명을 선택해 해당 보유 기록과 뉴스 검색으로 이동한다. 누락된 분류는 미입력으로 표시한다. ETF 지수는 ETF 기록만 묶고 입력 명칭이 같은 항목을 연결한다. 비중은 해당 분류의 서버 계산값이 있을 때만 표시한다. ETF 실제 구성 기업·구성 비중을 추정하지 않으며 거래 통화와 실제 환율 노출을 같다고 표시하지 않는다. 이 지도는 자동 증권사 연동이나 새로운 시세 수집 기능이 아니다.

## 기업·뉴스·게임

- 기업 탐색의 검색 폭을 부모 레이아웃에 맞춘다. 후보의 선정 이유·위험·근거는 보존하면서 중첩 상자와 반복 주요 버튼을 줄인다. PC 선택 기업 상세는 옆에 남고 좁은 화면에서는 Drawer로 읽는다.
- 회사 검색·시세 화면은 PC 차트 옆에 내 보유와 분석 근거를 배치하고 모바일에서는 세로로 읽는다. 연결 근거 기사 제목의 HTML 엔티티를 정리한다.
- 뉴스는 검색 한 줄과 관심 키워드를 먼저 제공하고 기사 목록을 상자 대신 구분선으로 읽는다. 모바일 웹 날짜 필터는 바텀 Drawer, Android는 별도 Modal과 기존 네이티브 달력으로 선택한다. 잘못된 날짜·역전된 기간은 적용을 막는다. 뉴스 기본 응답은 전체 저장 뉴스이며 관심 키워드를 누르면 해당 조건으로 검색한다. 여러 관심 기업의 자동 통합 피드로 주장하지 않는다.
- 게임 순위는 독립 도구로 유지하고 규칙·중간 종료는 더보기로 이동한다. 등록은 완주 조건이 충족됐을 때만 도구에 노출하며 종료 결과에서도 선택적으로 공개한다. 대기 중 연출 건너뛰기·원장·가상 표시·고정 주문 영역은 유지한다.
- 게임 회고에는 내 선택 → 가상 사건 → 가격 변화 → 내 자산의 타임라인을 추가한다. 실제 게임 드라이버와 평가 결과를 사용하고 과거 규칙의 원인 미확인 상태를 현금 관찰로 오인하지 않도록 처리한다. 실제 시장 뉴스의 확정적 인과 관계로 사용하지 않는다.

## 계정·설정·도움말

계정 연결 제목과 상태 배지가 작은 화면에서 어색하게 잘리지 않도록 배치한다. 설정은 세로 읽기 지면과 구분선으로 정리하고 저장되지 않은 변경·권한별 운영 기능을 유지한다. 도움말의 카테고리·질문 목록은 유지하고 검색을 제목 아래로 붙인다. 계정·기록 삭제 동의, 개인정보·오픈소스 고지, 자료 기준·투자 참고 안내는 유지한다.

## 검증과 한계

- 로컬 web build/lint, mobile type/lint 성공. 웹 lint의 기존 푸시 effect 경고 1개는 유지된다.
- 투자 연결의 등록 근거/서버 비중/ETF 한정 및 뉴스 날짜·윤년·역전 경계 5개 테스트 성공. CI에 동일 검사를 추가한다.
- 가상 API로 7개 화면 × 7개 폭(1,920/1,366/1,024/900/768/390/360px), 다크 5개 화면 검증. 연결 묶음·근거·기간 오류 및 정상 적용·등록 취소 초점·모바일 첫 자산/기사 위치·하단 메뉴·가로 넘침을 확인한다. 실제 운영 쓰기 0.
- 주간 게임 4개 폭에서 분야/보유 필터·주문 초기화·마지막 주 종료·선택 공개·작은 화면 모달 회귀 성공.
- 시험 데이터는 실제 운영 데이터나 실제 투자 분석 품질의 확인을 의미하지 않는다. Android 실제 설치·TalkBack·실제 이용자 관찰은 별도 미확인으로 유지한다. APK/EAS 빌드는 사용자 요청에 따라 보류한다.
- CI/머지/웹 배포와 배포 후 회귀 결과는 기존 WEB-38 context 및 Next-Tasks에 별도로 갱신한다. 서버 계산·DB·원장을 수정하지 않는다.
