# 측정 범위

기존 규모 검사는 합성 기업3000개와 단순 symbol 조회 계획만 검사해 실제 서비스의 전체 메타데이터/시세 JOIN·정렬·COUNT와 차이가 있었다. 이번 검사는 서비스에서 사용하는 SQL 생성 경로를 공유해 계획을 대조한다.

pg_trgm은 짧은 초성/한글 부분 일치에서 이점이 작을 수 있다. 전용 CI DB에서 실제 계획과 공간 비용을 확인하고 운영 도입 여부를 판단한다. Production URL은 TestDatabase가 거절한다. Render 배포 완료 후 공개 GET10건은 정상이나 BE-43 공식 기준값 설정 수치는 서버 집계 로그가 없어 아직 직접 확인하지 못했다.

서비스 시간은 결과 비교 검사 시간을 제외한7회 중앙값/최댓값이다. 계획의 SQL Execution Time은 각 단계의 단일 EXPLAIN ANALYZE 관측으로 서비스 중앙값과 직접 합산하지 않는다. 고정된 기존→후보 순서·전용 localhost DB·작은 표본·시세 행수 차이로 운영 개선율을 주장하지 않는다. 기존 테이블과 시세 행 전체는 후보 비교 전후 같음을 확인한다.
