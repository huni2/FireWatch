# FireWatch Play 데이터 보안 입력 초안

2026-10-10 코드 대조. Play Console에 제출한 답변이 아니다. 최종 Android 설치본·제공업체 설정/계약·공개 방침과 대조 후 입력한다. 패키지는 `com.firewatch.mobile`이며 공개 방침은 https://firewatch-eqp.pages.dev/privacy, 삭제 요청은 https://firewatch-eqp.pages.dev/privacy#delete-account다.

## 데이터 유형별 입력 근거

아래 유형은 공식 분류에 대한 **코드 기반 후보**다. ‘선택’은 해당 데이터를 제공하지 않아도 다른 기능을 쓸 수 있다는 뜻이다. 특정 기능을 누른 뒤 필수 입력이라는 사실과 구분한다. 금융·검색·문의 분류는 실제 입력 의미와 최종 SDK 동작을 확인해 결정한다.

| 실제 자료와 코드 | Play 분류 후보 | 수집·일시 처리 여부 | 목적 후보 | 선택 여부와 남은 확인 |
|---|---|---|---|---|
| Google 이메일·고유 식별자 / AppUser, GoogleIdentityVerifier | 개인 정보 → 이메일 주소·사용자 ID | 서버 저장, 일시 처리 아님 | 계정 관리·앱 기능·보안 | 로그인 선택. 로그인하지 않고 시장/게임 기능 이용 가능 |
| 공개 순위 닉네임 / GameRankingService | 개인 정보 → 이름 | 프로필/순위 서버 저장 | 앱 기능 | 순위 등록 선택·공개 동의. Google 표시 이름을 자동 수집한다고 기재하지 않음 |
| 기기 UUID·알림 토큰 / deviceId, UserSettings | 기기 또는 기타 ID | 요청 전송·서버 저장, 일시 처리 아님 | 앱 기능·알림 전달·보안 | 기기 ID는 익명 기록 구분에 필요. 푸시 토큰은 알림 등록 선택. 같은 유형의 필수/선택이 섞이는 경우 Console 기준으로 대조 |
| 보유 기업·수량·매입가·현금·월 투자액·계좌 유형 / PortfolioService | 금융 정보 → 기타 금융 정보, 기록 의미에 따라 구매 내역도 검토 | 서버 포트폴리오/이력 저장 | 앱 기능 | 수동 등록 선택. 실제 주문·은행 계좌번호·결제·신용 점수 수집 기능은 확인되지 않음 |
| 투자 목표·기간·성향, 관심 종목·키워드 / PortfolioService, SettingsService | 앱 활동 → 기타 사용자 제작 콘텐츠/기타 활동 후보 | 서버 저장 | 앱 기능·맞춤 정보 제공 | 기록/관심 설정 선택. 금융 자료와 중복 분류는 입력 의미를 대조 |
| 검색어 / StockController → StockService.search | 앱 활동 → 인앱 검색 기록 후보 | 일부 검색어가 감사로그에 저장, 일시 처리로 답하지 않음 | 앱 기능·운영 진단 | 검색 선택. 전체 카탈로그 API의 모든 검색어가 영속 저장된다고 확대하지 않음 |
| 가상게임 진행·주문·턴·선택 순위 / GameSession, GameRankingService | 앱 활동 → 앱 상호작용/기타 활동 후보 | 기기별 게임 서버 저장 | 앱 기능 | 게임 선택. 가상 주문을 실제 금융 거래로 소개하지 않음 |
| 문제 신고 내용·답변 / CommunityController | 앱 활동 → 기타 사용자 제작 콘텐츠, 내용/메시지 기능에 따라 기타 인앱 메시지도 검토 | 계정 문의 서버 저장 | 앱 기능·개발자 커뮤니케이션 | 문의 제출 선택. 작성자가 민감한 자료를 넣을 수 있어 토큰/계좌 자동 첨부는 없음 |
| 앱/웹 버전·접수 화면·작업 상태·소요시간 / FeedbackInput, AuditLog | 앱 정보 및 성능 → 진단 후보 | 문의/감사 서버 저장 | 진단·보안 | 서버 타이밍과 사용자의 기기 성능 수집을 구분. 모든 사용자 진단이 선택이라고 단정하지 않음 |
| IP 주소 / SettingsController, SettingsRateLimiter | 사용 방식에 맞는 분류 추가 대조 | 설정 요청 남용 방지 및 일부 감사 저장 | 사기 예방·보안 | 위치 추론 코드는 확인하지 못함. IP 자체를 무조건 위치로 분류하거나 제공업체의 위치 추론이 없다고 단정하지 않음 |

SDK나 인프라의 별도 식별자·진단·로그 처리도 최종 목록에 반영한다. `package.json`에 라이브러리가 있다는 사실만으로 실제 SDK 수집 범위를 확정하지 않는다. 앱에 광고·분석 SDK가 없다는 이유로 ‘수집 없음’으로 답하지 않는다.

## 외부 처리·공유 판단

| 경로 | 코드에서 확인한 전달 | 제출 전에 대조할 것 |
|---|---|---|
| 앱 → Render → Supabase | 로그인·설정·보유·게임·문의·감사 | 실제 운영 리전·처리 계약·보관·DB 접속 암호화 설정 |
| Android → Expo Push Service → FCM | Expo 토큰·알림 제목/본문 | 최종 설치본의 알림 SDK 처리, 업체별 보관/삭제와 계약 |
| Google 로그인 | ID 토큰 검증·Google 식별자/이메일 | 설치본 로그인 SDK와 서비스 제공 범위 |
| Gemini | 시장 지표·뉴스 | 현재 생성 인자에 이메일·세션·개인 보유 없음. 추후 개인 자료 전달 시 목록 변경 |
| 공개 순위 | 동의한 닉네임·조건·수익률·시각 | 사용자 공개 선택과 동의 UX, 철회/삭제 후 공개 제거 |
| 웹 Cloudflare·브라우저 푸시 | 웹 페이지, 브라우저 구독 endpoint/키·메시지 | Android 제출과 웹 서비스 범위를 구분하고 업체별 실제 로그/계약 확인 |

‘외부에 전달’과 Play의 ‘공유’ 체크는 같은 판단이 아니다. 제공업체가 개발자의 지시에 따라 처리하는지 등 공식 예외와 실제 계약을 대조한다. 업체명을 보고 모두 공유 없음/모두 공유 있음으로 일괄 답하지 않는다.

## 제출 전 확정할 항목

- 앱은 Google 계정 연결로 서버 계정을 생성할 수 있다. 계정 기능이 없다고 답하지 않는다.
- 앱 설정의 계정 삭제와 웹 요청 경로를 제공한다. 기기 게임·감사·백업의 별도 이행은 [삭제 운영 절차](deletion-operations.md)대로 확인한다.
- 배포 URL은 HTTPS다. 최종 설치본의 모든 사용자 데이터 경로·SDK·서버 DB TLS를 대조하기 전 ‘모든 전송 암호화’를 완료로 표시하지 않는다.
- 전송 암호화와 저장 암호화, 세션 해시 저장을 구분한다. PR#57은 신규 감사 인증 헤더를 가리며 기존 감사/백업의 원문 정리를 보장하지 않는다.
- 국외 처리 국가·계약, 수동 요청 처리기간, 감사/백업 보관기간, 실제 백업 확보는 미확인이다. Console 선택지를 채우기 위해 임의 수치를 넣지 않는다.
- 사용자의 APK 보류 결정을 따른다. 최종 SDK 실물 점검을 위해 이 문서 작성 중 EAS 빌드를 요청하지 않는다.

## 공식 근거

[Play 데이터 보안 안내](https://support.google.com/googleplay/android-developer/answer/10787469?hl=ko)는 앱과 SDK의 기기 외부 전송, 가명 자료, 선택 여부, 제공업체 예외를 설명한다. 위 금융·활동 분류 후보는 그 분류와 FireWatch 코드의 대조 결과이며 Google의 개별 앱 판정이 아니다.

[계정 삭제 안내](https://support.google.com/googleplay/android-developer/answer/13327111?hl=ko)는 앱 내 경로·웹 요청과 계정 관련 자료 처리를 다룬다. 2026-10-10 확인. 실제 계정 관련 자료의 삭제와 정당한 보관 범위 확인이 남아 있으므로 제출 완료로 처리하지 않는다.
