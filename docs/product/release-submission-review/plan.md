# BE-21 Play 제출과 삭제 운영 대조

기존 BE-21의 Data Safety·삭제 요청 운영 항목을 공식 Play 안내와 실제 코드/SDK에 대조한다. 데이터 유형별 수집·목적·선택 여부·공유 판단의 근거를 준비하고 계정/기기 기록·백업의 삭제 요청 절차를 문서화한다.

현재 StockService.search의 검색어가 감사 요청에 저장되는 경로를 확인했다. 공개 개인정보 안내의 누락을 보완하고 서버 주석의 기기 게임은 PII가 아니라는 잘못된 단정을 정정한다. 처리기간/국외 계약/보관기간/실제 운영 백업을 확인 없이 확정하거나 Play 제출하지 않는다. 기존 BE-21/Issue#56 사용·APK0.

운영 확인 단계(2026-10-10). main CI를 대조하고 새 브라우저 컨텍스트로 배포 웹의 개인정보 최신 고지/삭제 요청 링크·비로그인 감사 화면을 PC/모바일 폭에서 확인한다. 모든 변경 HTTP 요청을 차단하고 실제 인증 토큰을 사용하지 않는다. 서버 익명 권한 경로2GET도 대조한다. 이 확인은 실제 로그인/운영 감사 원문/삭제·백업 이행을 대체하지 않는다.

2026-10-10 BE-21 추가 검증: 시험 DB에 삭제 대상 계정의 마지막 삭제를 막는 외래키를 구성하고 실제 HTTP 계정 삭제가 실패했을 때 공유 설정·포트폴리오/이력·기기 연결·세션·문의가 모두 롤백되는지 확인한다. 원인을 제거한 뒤 같은 세션으로 재시도하여 정상 삭제와 다른 계정 보존을 확인한다. 런타임/운영 DB·보관 정책 변경 없이 기존 Issue#56에서 처리한다.
