# 파비콘과 편안함 점검 — 2026-10-11

## 확인 범위

배포 웹에서 시험 API를 사용해 1366px PC/390px 모바일 폭으로 자산·탐색·뉴스·계정·지표·종목·브리핑·도움말·설정과 빈 자산 화면을 캡처했다. 운영 쓰기와 JS 오류는 0이었다. 게임은 직전 배포 검증 이미지로 평가했다. Android 설치본 평가나 실제 사람의 사용성 검증은 아니다.

## 판단

기본 라이트, 한 가지 주요 행동, 읽기 쉬운 숫자, 하단 네 메뉴와 위험의 펼침 방식은 편한 투자 점검 앱의 방향에 맞는다. 현재 화면이 토스와 같은 수준으로 마찰이 적다고 확정할 근거는 없다. 로고 교체와 색 추가만으로 사용성이나 고유한 인상이 완성되지는 않는다.

| 화면 | 확인한 문제 | 다음 개선 방향 |
|---|---|---|
| 자산 등록 후 | 390px에서 자산 구성 요약이 보유 목록 뒤에 있어 첫 화면에 보이지 않는다. 시세 기준·매입원금 기준·수량·수정 설명이 시선을 나눠 가진다. | 총액 아래에 가장 중요한 구성 결과 한 줄을 먼저 놓고 상세 기준은 펼침으로 묶는다. 자산 목록 행은 기업명·평가액·수익 변화를 우선한다. |
| 기업 탐색 | 추천 1개인 상태에서도 검색·탭·자료 기준 다음에 빈 공간이 커서 첫 기업이 아래로 내려간다. | 검색과 목록 사이 간격을 좁히고 기업명 바로 아래에 핵심 근거 한 줄, 개인 보유 연결을 짧게 둔다. 위험 전문은 상세에서 계속 제공한다. |
| 계정 | 로그인 카드와 연결 설명에 더해 모바일 푸터의 여러 지원 링크가 화면을 채운다. | 로그인 전에는 로그인 행동과 기록 보존 설명을 우선하고, 문의/고지 링크를 계정 메뉴와 일관되게 묶는다. 법적 문서는 계속 접근 가능해야 한다. |
| 게임 로비 | 시작 행동과 실제/가상 구분은 명확하다. 순위·규칙·시작 설정과 보조 설명은 작은 텍스트 도구가 많다. | 시작 행동을 유지하면서 보조 도구의 크기·간격·표현을 통일한다. 거래/회고의 정보 밀도는 실기기에서 확인한다. |

색은 주황 행동·청록 연결·남색 시장의 역할을 유지한다. 추가 장식 색보다 간격과 읽을 문장 수를 줄이는 효과가 크다. 서로 다른 금융 기준은 지우거나 하나로 합쳐 오해시키지 않는다.

## 이번 수정

기존 파비콘은 차트·AI 배지·브랜드 글자까지 포함한 복잡한 PNG였다. 헤더의 불꽃 경로를 재사용한 주황 바탕/흰 심볼 SVG와 32px PNG 대체 파일을 추가했다. 16/32/64px 밝은·어두운 배경 미리보기와 production build를 확인했다. 새 경로로 기존 파비콘 캐시와 구분한다. 일반 로고 이미지·헤더 심볼·Android 런처 아이콘은 바꾸지 않는다.

기존 WEB-38/Issue #62에 기록하며 새 과제를 만들지 않는다. 위 개선 방향은 리뷰이며 이 파비콘 변경에서 화면 구조를 추가로 수정하지 않았다. APK/EAS는 계속 보류한다.
