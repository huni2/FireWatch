# 나에게 맞는 투자 방식 찾기

웹 `/investment-style`과 Android의 내 투자 화면에서 로그인 없이 이용하는 10문항 자기점검입니다. 소요 시간은 약 2분이며 서버 연결을 기다리는 중에도 시작할 수 있습니다. 결과는 임상·통계적으로 검증한 성향 진단이나 금융상품 적합성 평가가 아닙니다.

## 질문과 결과

목적, 사용 시점, 예비 자금, 손실의 생활 영향, 하락 경험, 변동을 감수하려는 마음, 관리 시간, 의사결정 과정, 투자 경험, 주변 수익 이야기에 대한 행동을 묻습니다. 모든 문항에 모름·미정 선택지가 있으며 임의로 중간 점수로 바꾸지 않습니다.

유형은 선호하는 관리 과정에 따라 루틴 관리형·직접 탐구형·비교 정리형·간편 점검형으로 표시합니다. 선호가 미정이면 탐색 중으로, 단 짧게 확인하고 싶다는 응답이 있으면 간편 점검형으로 표시합니다. 결과 근거인 관리 시간과 선호 답변을 함께 제공합니다. 수익률, 실력 점수, 종목·상품·비중·매매 시점 추천은 생성하지 않습니다.

감수하려는 마음과 생활상 여력을 분리합니다. 1년 안에 필요한 돈, 비상 지출과 겹치는 돈, 큰 생활 영향을 답하면 기대 수익이 높아도 생활 제약이 상쇄되지 않습니다. 사용 시점·예비 자금·손실 영향 중 미정이 있으면 추가 확인이 필요하다고 표시합니다. ‘여력 확인’은 투자 가능한 금액의 확정이 아닙니다.

시간과 탐구 선호의 불일치, 생활 제약과 높은 변동 선호의 차이, 주변 수익을 따라 서두르는 답변을 설명합니다. 다음 행동은 목적·사용 시점 정리와 기존 보유 이유·점검 기록으로 연결합니다. 보유 자산이나 투자 설정을 자동 수정하지 않습니다.

## 저장과 삭제

답변은 메모리에서 처리하며 서버·AI·게임 순위로 보내지 않습니다. ‘결과 저장’을 선택해야 웹 localStorage 또는 Android SecureStore에 전체 답변·버전·저장 날짜를 보관합니다. 로그인 계정·다른 기기와 동기화되지 않습니다. 개인정보 처리방침에도 같은 범위를 명시합니다.

재검사 중에는 이전 저장 결과를 유지하며 새 결과 저장 성공 후 교체합니다. 저장 실패 시 화면 답변과 이전 저장을 유지합니다. 손상되었거나 다른 버전의 저장은 자동 삭제하지 않고 안내와 수동 삭제를 제공합니다. 저장 결과 삭제는 확인 후 실행하며 서버의 보유 자산·메모에는 영향을 주지 않습니다. 기기 결과는 계정 삭제와 별도로 삭제해야 합니다.

웹 화면 내 돌아가기·새로고침/닫기 및 Android 화면 버튼·하드웨어 뒤로가기에서 작성 중 답변 유실을 안내합니다. 웹의 다른 전역 메뉴 이동은 차단하지 않으며 중간 답변을 자동 복원하지 않습니다.

## 검증과 한계

공통 규칙 테스트는 모름 처리, 생활 제약 48조합, 유형 근거, 저장 데이터 검증을 포함합니다. 웹 브라우저 검증은 1280px·360px·360px 다크 모드에서 10문항, 이전 답변 유지, 명시적 저장·복원, 저장 실패, 삭제 취소·완료, 손상 데이터 복구, 서버 미전송, 가로 넘침을 확인합니다. Android는 타입·린트·기존 회귀 검사 및 AAB 빌드로 확인하며 실제 기기의 TalkBack·뒤로가기·저장 복원은 별도 확인이 필요합니다.
