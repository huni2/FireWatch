# 출시 전 데이터 처리 대조와 웹 계정 삭제

BE-21의 정책·실제 처리 대조를 진행한다. 보유 기록·게임 기록·세션·문의·푸시·외부 서비스에 전달하는 자료를 코드와 대조하고 개인정보 안내를 수정한다. WEB-39는 기존 인증된 DELETE /api/auth/account를 웹 계정 화면에서 확인 후 실행하는 경로와 공개 개인정보 페이지의 삭제 요청 링크다. APP-31은 기존 앱 삭제 확인 문구를 실제 범위에 맞춘다. 운영 계정은 삭제 시험에 사용하지 않는다.

계정과 공유 자료 삭제는 기존 서버 계약을 따른다. 기기별 게임 기록·보안 감사로그·기존 백업은 자동 삭제되지 않으므로 이를 숨기거나 개인정보가 아니라고 단정하지 않는다. 계정 관련 게임의 삭제 범위·처리기간·국외 처리 계약·실제 백업 확인은 BE-21의 출시 확인 항목이다. 안내 추가를 법률 검토나 Play 승인 완료로 표현하지 않는다.

검증은 계정 삭제 확인/취소/실패/성공 fixture, 로그인·로그아웃 회귀, 공개 삭제 안내 진입·모바일/PC 배치, 웹 build/lint·앱 타입/lint·CI다. APK/EAS 빌드는 보류한다.
