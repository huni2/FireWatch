2026-10-09. BE-21에서 직접 진행할 수 있는 실제 데이터 처리 대조를 선택했다. 수동 보유 기록이 방침에서 누락됐고 Expo를 Google 업체로 묶은 오류가 있었다. AuthService.deleteAccount는 공유 포트폴리오/이력·설정·연결·계정을 지우고 문의/숨김/순위는 FK cascade, 기기별 게임은 보관한다. 게임 기록을 개인정보가 아니라고 단정한 서버 주석은 정책 근거로 사용하지 않는다. 웹에 직접 삭제 경로가 없어 기존 API와 공개 요청 경로를 연결한다. 실제 운영 삭제·외부 전송·APK 빌드는 하지 않는다.
