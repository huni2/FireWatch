# 투자 점검 흐름과 화면 우선순위 정리 — 2026-10-13

기존 WEB-38(#62)의 첫 이용자 흐름 개선과 사용자가 요청한 디자인 리뷰 후속조치다. 새 과제는 생성하지 않는다.

## 반영한 화면

- Android 빈 자산 화면: 설명 → 개인 기록에 저장되지 않는 ETF 지수명 비교 예시 → 첫 자산 등록 순서. 투자 정보의 참고용·손실 가능성 요약은 유지하고 상세 안내는 펼쳐보기로 연결한다.
- Android 자산 화면: 평가액 → 확인할 점과 점검 버튼 → 자산 구성 → 기록 추가·수정 목록. 점검 버튼은 구성으로 이동하고 분야·통화·입력 지수명 연결을 펼친다. 웹의 PC 다단 구조는 유지하며 좁은 웹에서도 구성부터 보여준다.
- Android 기업 탐색: 국가와 추천 조건을 공통 바텀시트로 묶어 적용·초기화한다. 분야는 가로 목록, 기업은 행 전체가 상세 진입 버튼이다. 상세에서 상단 탭을 숨기고 원래 화면으로 돌아간다. Android 뒤로 가기도 해당 복귀를 처리한다.
- 웹 기업 탐색: 국가 필터를 펼치고 접을 수 있다. 좁은 화면에서 분야를 가로 탐색한다. PC의 목록·상세 분할 구조는 유지한다.
- Android 종목 상세: 관심 기업 동작을 먼저, 보유 기록 등록을 보조 동작으로 배치한다. 적은 시계열에서도 마지막 가격과 툴팁이 화면 안에 들어오도록 차트 간격을 조정한다. 바깥 터치 해제 동작은 유지한다.
- Android 게임: 소식 / 기업·주문 / 내 자산으로 구분한다. 소식은 시장 설명 → 가상 뉴스 → 관찰 픽 순서. 분야·검색·주문 상태는 상위에서 유지하며 새 턴에는 소식으로 돌아간다. 고정 다음 턴 버튼 옆에 이번 거래 건수를 표시한다.
- 웹 게임: 소식을 관찰 픽·기업 목록보다 앞에 배치한다. PC의 오른쪽 고정 주문은 유지한다. 요약 게임머니의 소수점을 덜어내고, 주문 확인 금액의 정밀도는 유지한다.
- 공통 선택 컨트롤 `ChoiceTabs`를 기업 탐색·게임에 적용한다. 게임 카드 간격·본문 크기에 공유 토큰을 적용하고 사용하지 않는 개별 버튼 스타일을 제거한다. 긴 소수 비중은 표시할 때만 소수 첫째 자리까지 정리한다.

## 배포 및 실제 검증 범위

최초 소스 반영 시점에는 APK·AAB·EAS 빌드를 실행하지 않았다. README의 배포 APK는 1.0.9(빌드 14) 그대로이며 이 후속 수정은 포함되지 않는다. 새 APK는 별도 요청 때 빌드한다.

React Native 웹 재현은 Android 네이티브의 키보드·뒤로 가기·접근성 글자 확대를 대신 검증하지 않는다. 실제 APK 확인 및 WEB-38의 첫 이용자 실사용은 완료로 처리하지 않는다. 서버·DB·운영 데이터·로그인/푸시 키 변경은 없다.

사용자의 후속 APK 요청으로 위 UI 수정은 APK 1.0.10/빌드15에 포함했다. 앞의 미포함 안내는 최초 소스 작업 시점의 1.0.9 기준이다. [파일 검증](../android-preview-20261009/android-110-build.json). 실제 Android 네이티브 검증은 미완료다.

## 1.0.10 실사용 제보: 읽기 창 스크롤·닫기 후속 수정

사용자가 시장 브리핑 등 공통 바텀시트에서 본문 아래가 잘리고, 읽으려는 터치에 창이 닫힌다고 제보했다. 기존 APK는 재빌드하지 않으며 다음 요청 시 포함할 소스 수정이다.

- 배경 한 번 터치로 닫지 않는다. 오른쪽 닫기 버튼·Android 뒤로 가기는 유지한다. 손잡이는 16pt 이상 이동해야 드래그가 시작된다. 본문은 창을 움직이거나 닫는 제스처를 처리하지 않는다.
- 본문은 독립적인 React Native `ScrollView`로 변경한다. 기존 BottomSheetScrollView의 내부 스크롤 상태·제스처 등록을 사용하지 않는다. 읽기 영역의 flex 최소 높이, 하단 여백과 안전 영역을 유지하며 제목·하단 행동은 스크롤 밖에 둔다.
- 동일 공통 컴포넌트를 사용하는 브리핑, 기업 상세·필터, 게임 규칙·순위·결과·주문·자산 상세·회고, 공지 팝업에 적용한다. 별도의 개인정보 전문·보유 기록 편집 모달은 이번 변경 대상이 아니다.
- Mobile TypeScript 및 `src`/새 테스트 lint 통과. 관련 회귀 검사 27개 통과. 읽기 창의 닫기 경로·저장 중 닫기 차단·스크롤 계약 3개를 CI에 추가했다.
- React Native web 격리 화면 360×740 라이트·다크: 40문단 브리핑 터치로 265px 스크롤, 본문·배경 탭 후 유지, 마지막까지 이동(본문 2,287px / 표시 영역 512px / 끝 위치 1,775px), 닫기 버튼과 게임 규칙 열기·닫기 확인. JavaScript 오류 0.
- 이 결과는 실제 Android APK의 네이티브 제스처·키보드 검증을 대신하지 않는다. 정확한 실기기 원인이 확정됐다고 기록하지 않으며, 수정된 APK 실수신 확인은 남아 있다. 공개 1.0.10 APK 및 README 다운로드 링크는 변경하지 않는다.

### 주가 차트의 작은 변동 읽기

같은 작업 중 사용자가 하루·일주일 차트에서 상승과 하락이 구분되지 않는다고 제보했다. Android 주가 차트는 가격 축의 하한을 지정하지 않고 영역을 채우고 있었고, 웹도 영역 채움 차트를 사용했다.

- Android·웹 주가 차트를 면 채움 없는 직선 차트로 통일한다. 선택 기간 첫 가격을 점선으로 표시하고 마지막 기록과 비교한 실제 변동 금액·비율을 표시한다. 최신 제공 시세와 기간 변화는 별도 기준임을 문구로 구분한다.
- 상승 빨강·하락 파랑·보합 회색을 사용한다. 색 이외에 부호·금액·비율도 제공한다. 작은 축 눈금은 `만` 단위로 줄이지 않아 서로 다른 가격이 같은 눈금처럼 보이지 않도록 한다.
- 세로축은 관측 가격 범위와 여백에 맞춘다. 최소 시작 가격의 0.5% 범위와 여백을 확보해 미세한 움직임을 과장하지 않는다. 데이터의 실제 가격은 바꾸지 않으며 툴팁은 축 오프셋을 적용하기 전 원래 가격을 사용한다.
- 양수·유한 가격만 표시한다. 기록 한 개는 상승·하락 그래프를 만들어내지 않고 추가 기록을 기다리는 안내를 표시한다. 시장 지표와 가상게임 그래프는 변경하지 않는다.
- 공유 계산·실제 렌더 설정 회귀 검사 3개 추가: 소폭 상승·하락, 보합·누락·큰 변화, 축을 좁힌 후 원래 툴팁 가격 유지. Android 웹 격리 화면 360×740 라이트·다크의 상승·하락·보합 6개 조합에서 +0.10%·−0.10%·0.00%와 선 색, 하루 기간 선택, JavaScript 오류 0을 확인했다. 실제 APK 검증은 별도다.
