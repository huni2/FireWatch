# Android 사용성 리뷰 후속 수정 — 2026-10-13

전체 메뉴와 화면 구조를 유지한 채 사용자가 승인한 리뷰 보완점을 반영한다. 기존 WEB-38(#62)의 후속 기록이며 새 과제를 파생하지 않는다.

## 변경

- 하루 주가 차트의 30초 갱신과 최초 로딩을 분리했다. 같은 기업·기간의 기존 기록을 갱신 중/실패 후 유지하고, 실패 안내와 재시도 버튼을 제공한다. 요청 중 다음 자동 갱신을 중복 실행하지 않는다. 기업·기간이 바뀌면 이전 기록은 즉시 숨기며 늦은 응답을 무시한다.
- 기록이 없는 기간은 ‘선택한 기간에 가격 기록이 없어요’와 ‘1개월로 보기’로 안내한다. 이미 1개월인 경우 재조회한다.
- 수량·매입가·현금·기간·월 추가금 입력의 정상적인 천 단위 쉼표와 앞뒤 공백을 처리한다. 잘못된 그룹(`10,00`), 지수 표기, 음수, 소수점 다섯 자리 등을 임의로 다른 값으로 바꾸지 않는다. 입력 문자열과 커서는 그대로 유지하고 수량·금액의 해석값을 표시한다. 기존 수량/매입가 상한과 서버 검증은 유지한다.
- 자산 요약에 평가에 포함된 종목의 실제 `quoteAsOf`를 표시한다. 여러 기준 날짜·기준 날짜 미확인·달러 자산의 환율 날짜·현금만 등록한 경우를 구분한다. 기록 수정 시각(`updatedAt`)을 시세 시각으로 사용하지 않는다.
- 기업 탐색의 중복 ‘기업 찾기’ 제목을 제거한다. 게임 투자 노트 제목은 소식 화면에서만 표시한다. 순위·규칙·마무리 메뉴 위치와 탭 구조는 유지한다.
- 44 높이/너비의 작은 컨트롤과 선택 항목을 최소 48로 맞춘다. 차트 기간 선택은 탭 역할·선택 상태를 전달한다. 시스템 글씨 확대와 TalkBack 실기기 확인은 별도다.

## 검증

- Mobile TypeScript / 수정 범위 lint 통과.
- 모바일 회귀 검사 81개 통과. 새 입력·시세 기준·갱신 유지·오래된 응답 무시 계약 4개를 CI에 추가했다.
- 360×740 라이트·다크 격리 브라우저에서 `1,000`주와 `100,000` 매입가가 숫자로 저장되는 것, 해석값 안내, 시세 기준 표시, 선택된 하루 탭/48 터치 높이, 중복 제목 제거를 확인했다.
- 실제 30초 자동 갱신에 1.5초 지연과 503 실패를 넣었다. 갱신 중과 실패 후 +0.10% 차트가 유지됐고 재시도로 +0.20% 새 기록을 표시했다. 하루 요청은 초기·실패·재시도 3회, JavaScript 오류 0.

브라우저는 로컬 시험 API를 사용하며 운영 데이터에 쓰지 않는다. 실제 Android 로그인·키보드·뒤로 가기·드래그·TalkBack은 이 검사로 통과 처리하지 않는다. 백엔드·DB·키 변경은 없다. APK/AAB/EAS 빌드를 실행하지 않으며 공개 1.0.10 APK와 README 설치 링크는 변경하지 않는다.
