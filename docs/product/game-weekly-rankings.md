# 게임 주간 순위 (2026-10-07)

게임 종료 시 공개 등록을 선택한다. 진행 중인 턴은 사용자가 직접 등록 창을 열며 매 턴 자동 팝업이나 자동 등록은 없다. Google 로그인은 공개 등록/본인 기록 관리에만 필요하다. 조회는 공개다. 게임 닉네임을 2~16자로 지정하고 공개 동의를 체크해야 등록한다.

## 비교 규칙

- 자유 플레이 순위다. 각 게임 시드가 다르므로 같은 시장에서 겨루는 대회가 아니다. 화면에 이를 고지한다.
- 24턴을 끝까지 진행해 종료한 기록은 FINISHED, 진행 중 또는 중도 종료 기록은 PROGRESS로 나눈다. 2턴 이후부터 등록하며 같은 턴 번호끼리 비교한다.
- 총자산이 아닌 시작 대비 수익률을 서버 장부와 평가액으로 계산한다. 난이도(2,000만/1,000만/500만)와 공매도 조건별 리그를 나눈다.
- 등록 주 기준으로 KST 월요일 00:00부터 다음 월요일 00:00까지 집계한다. 동일 게임/턴/기록 종류는 재전송해도 하나이며 다음 주에 같은 기록을 재등록할 수 없다.
- 계정별 리그 최고 기록 하나만 표시한다. 원점수 내림차순, 동률은 등록 시각/고유 ID 순으로 결정한다. 화면 점수는 소수 둘째 자리까지 표시한다.
- 계정당 주200개 등록 상한, 조회20건 페이지, 우승자30건 페이지. OpenSearch/외부 AI/시세 서비스/유료 서비스는 추가하지 않는다.

## 공개와 보관

이메일/계정 ID/기기 ID/세션 ID/보유/거래 상세는 공개 응답에 없다. 게임 닉네임, 원점수, 조건, 턴, 주, 등록 시각, 공개 여부만 응답한다. 닉네임은 계정별 고정이며 중복/이메일 형식 입력을 차단한다. 다른 사용자의 기록을 철회할 수 없다. 내 기록도20개씩 페이지로 조회해 예전 기록을 철회할 수 있다.

사용자가 공개를 철회하면 주간 순위·우승자 목록에서 숨긴다. 철회 기록은 중복 등록 방지를 위해 비공개로 보관하며 재공개하지 않는다. 계정 삭제는 닉네임·점수·우승자 연결 기록도 FK cascade로 삭제한다. 개인정보 방침과 모바일 제출 검토 목록을 수정했다.

## 주간 우승자 확정

주가 지난 뒤 첫 순위 요청에서 미마감 주의 완주 기록을 원자적으로 집계해 조건별1위를 별도 테이블에 저장한다. 추가 스케줄러나 무한 재시도 없이 재시작 후에도 마감 상태를 유지한다. 같은 주를 두 요청이 동시에 마감하지 않도록 DB 상태 행을 잠근다. 닉네임/점수는 마감 후 변경할 수 없다. 우승자가 철회/삭제해도 차순위에게 과거 우승을 다시 배정하지 않는다. 진행 중인 턴 기록은 명예의 전당에 포함하지 않는다.

## 검증

GameRankingIntegrationTest: 동의 전 미등록, 인증/본인 게임/턴 일치, 클라이언트 점수 무시, 서버 장부 점수, 동시 중복 제출, 리그/최고기록 분리, 한국 시간 월요일 경계, 우승자 확정/철회/계정 삭제, 공개 개인정보 미노출. PostgreSQL CI에도 같은 시험을 추가한다.

브라우저 fixture는 종료 등록 거절 시 POST0, 동의 필수, 등록/조회/철회 및 1366/390/360px, 익명 로그인 안내를 검사한다. 실제 운영 DB에 임의 사용자·점수는 넣지 않는다. Android는 타입/린트와 번들 검증을 하되 새 APK 설치/실기기 순위 검증은 별도로 남긴다.

후속: 실제 기업 목록/새 시뮬레이션 버전은 기존 리그와 섞지 않는 버전 정책을 먼저 정해야 한다(BE-28). 같은 시드·고정 기간의 주간 챌린지는 자유 플레이와 별도 리그로 확장할 수 있다.
