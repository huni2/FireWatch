# 기업 상세 버튼·팝업 후속 수정 (2026-10-12)

기존 WEB-38 / GitHub #62의 이용자 피드백을 처리한다.

- 보유 기록 등록: 링크에 AntD 클래스만 붙인 구현을 실제 primary Button + 내부 이동으로 교체. 라이트 흰 글자/짙은 오렌지, 다크 짙은 글자/오렌지를 컴포넌트 테마로 처리한다.
- 관심 기업: 웹·앱 모두 버튼 내부에 로딩 아이콘 자리를 확보해 저장 중 글자가 밀리지 않는다. 중복 클릭 차단, 완료 안내와 오류는 해당 상세 화면에 유지한다.
- 웹 Drawer: 공통 AppDrawer로 제목 왼쪽/닫기 오른쪽 끝을 고정. 계정 메뉴·기업 상세·보유 등록·투자 계획·뉴스 기간에 적용하며 저장 중 닫기 제한은 유지한다.
- 웹 Modal/Drawer: 닫기 터치 영역 44px, 제목·본문·하단 버튼의 여백과 정렬 기준을 공유한다. 확인 모달과 입력 패널의 기능 차이는 유지한다.
- 앱 보유 등록/투자 계획: 제목 왼쪽, 닫기 오른쪽. 키보드 닫기·변경 취소 확인·저장 중 닫기 차단을 유지한다.
- 이용자가 APK에서 발견한 문제임을 추가 확인했다. 앱 보유 등록 진입 버튼은 명암 대비가 큰 잉크/표면 색 조합으로 변경한다. 관심 해제 시 읽던 기업을 바꾸지 않아 엉뚱한 차트 로딩으로 전환되지 않는다.
- 앱 공통 ModalHeader를 보유/계획 입력·기업 상세·주문·순위·규칙·게임 결과·턴 돌아보기·개인정보·공지 창에 적용한다. 고정 제목과 오른쪽 48px 닫기, 테마 표면/본문 구분, 저장 중 닫기 제한을 공유한다.

## 검증

- 웹 production build / lint, 앱 TypeScript / lint 통과. 웹의 기존 useWebPushSubscription effect 경고 1개는 이번 변경과 별개다.
- 격리된 로컬 fixture에서 기업 상세 → 관심 등록 → 해제 → 보유 기록 등록을 확인했다. 운영 계정/투자 기록은 변경하지 않았다.
- 실제 렌더링된 보유 등록 버튼: 라이트 rgb(255,255,255) / rgb(185,77,11), 다크 rgb(24,17,13) / rgb(220,120,55).
- 등록 Drawer 헤더 위치: 제목 x=781.60, 닫기 x=1177.60 (폭 480px). 제목 오른쪽의 닫기 배치를 시각 확인했다.
- 최신 앱 소스를 Expo 웹 미리보기로 내보내고 360×800의 격리 fixture에서 확인했다. 보유 등록 진입 버튼은 rgb(23,32,46) 바탕/흰 글자, 입력 창 닫기는 x=292/폭 48px였다. 관심 등록·해제 도중에도 동일한 기업 상세가 유지됐으며 등록 창 진입·닫기를 확인했다. 테스트 fixture는 동의/로그인 상태를 대체하고 실제 계정·푸시·네이티브 환경을 검증하지 않는다.
- Android 실제 기기에서의 표시 확인은 다음 APK 검증에 남긴다. 이번 변경은 APK를 빌드하지 않는다. README APK 1.0.5에는 이 후속 수정이 포함되지 않는다.
