# UI/UX 리뷰 반영 — 2026-10-12

기존 WEB-38/Issue62 및 APP-21의 소스 후속이다. 새 과제/Issue를 만들지 않는다. 최초 이용자 관찰·실제 Android·Play 확인을 완료로 표시하지 않는다.

## 적용

- 기업 탐색: 상단 검색1개와 후보/분야/ETF 전환. 기존 전체 회사 검색과 ETF 목록을 같은 검색어로 사용한다. 분야는 기존 편집 목록이며 전체 상장사의 분야 분류라고 과장하지 않는다. ETF 목록의 국내/미국 필터·공식 출처·비용/환율 고지는 유지한다.
- PC는 결과/상세, 모바일 웹은 전체 drawer. 이름을 중복 표시하는 헤더를 줄이고 차트 축을25만처럼 표시한다. 웹 탐색 상태는 URL에 보관하며 다른 경로 이동 때 이전 탐색 URL로 덮어쓰지 않도록 보호한다.
- Android는 기업 탐색/뉴스/게임을 첫 방문 때만 마운트한 뒤 상태를 유지한다. ScreenActivity로 숨겨진 화면의 자원 조회/시세 폴링/로딩 애니메이션을 중단한다. 회사/뉴스를 새 대상으로 직접 여는 경우에만 상세를 재설정한다. Google 연결/로그아웃/현재 세션 무효화 때 보관 화면을 초기화한다. 같은 계정의 silent 세션 갱신 및 늦은 이전401은 화면을 초기화하지 않는다.
- 추천/뉴스 최초 조회가 느려도 검색·필터를 쓸 수 있다. 조회 중 후보0개 표시를 제거하고 실패한 뉴스는 같은 조건으로 재조회할 수 있다.
- 기업 상세→보유 기록 등록에서 선택 회사/이름/통화를 이어준다. 이미 등록된 회사면 수량 수정 폼을 연다. 매입가는 계속 선택이다. 수량 오류는 입력 옆에 표시한다. 저장 후 새 기록과 발견을 강조하고 다른 자산 추가를 제공한다. 서버 원장/계산 범위/매입가 미입력/가격 미확인 규칙을 변경하지 않는다.
- 자산 요약과 발견을 연결하고 Android에서 보유 목록을 구성보다 먼저 배치한다. 연결 지도는 추가 분석을 펼친 경우 보여준다.
- 뉴스는 제목의 회사명 포함 여부로만 구분한다. 의미 분석으로 직접 관련성을 보증하지 않는다. 본문 언급 기사도 삭제하지 않고 펼쳐 볼 수 있으며 원문 확인 안내를 유지한다.
- Android 게임 주문을 별도 시트로 분리한다. 픽/기업 선택→선택 자산/수량/총액/현금→고정 확인 버튼. 다른 자산 선택은 펼침, 닫기는 입력 유지, 다음 턴·새 게임·종료 시 입력 초기화. busy 닫기 차단·기존 금액 확인 Alert·idempotency/expectedTurnIndex는 유지한다. 오류는 시트 안에서 보인다. 실제 Android 키보드/뒤로가기/Alert 체결은 별도 확인이다.
- 게임 완료 회고는2개 우선 표시·더 보기. 웹 마스코트는 게임 시작과 묶고 순위/규칙은 보조로 유지한다. 기존 PC 우측 주문/다음 턴 고정 배치를 확인했다.
- 웹 상단에도 해/달 좌우 테마 스위치를 두고 계정 메뉴에서는 회사 검색을 제거해 기업 탐색으로 모았다. 계정 메뉴 이름/밀도, 후보 장식선/반복 안내를 정리했다. Android 투자 조건/분석 이력/상품 체크리스트는 더 보기에 모았다.

선택 분야 배경과 기업/뉴스 검색 입력은 라이트/다크 색상 토큰을 사용한다. 밝은 고정 선택 배경과 기본 검정 입력 글자를 제거한다.
