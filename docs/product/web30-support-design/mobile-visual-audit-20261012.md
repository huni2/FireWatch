# APK 시각·인터랙션 점검 (2026-10-12)

기존 WEB-38 / GitHub #62에서 진행한다. 신규 기능·파생 과제·APK 빌드는 추가하지 않는다.

## 적용

- 공통 ActionButton: 주요 행동은 잉크/표면 색으로 대비를 확보한다. 비활성은 흐린 투명도 대신 읽히는 보조 글자/바탕/테두리로 구분하고, 저장 중은 기존 대비와 고정 아이콘 자리를 유지한다. 최대 폭과 줄바꿈으로 긴 라벨을 수용한다.
- 자산 등록/수정·뉴스 검색/기간 적용·문의 접수·알림 등록/해제를 같은 버튼으로 처리한다. 알림은 실제로 누른 작업에만 진행 표시를 한다. API와 동의/권한 처리 방식은 변경하지 않는다.
- 기업 설명·뉴스 기간·공지·브리핑을 게임과 같은 AppSheet로 정리했다. 읽기 본문은 스크롤, 제목/닫기/하단 행동은 고정이다. 40px 손잡이 영역과 닫기 대안을 제공하며 처리 중 닫기 제한을 유지한다.
- 자산 입력은 전체 입력 화면과 키보드 대응·변경 취소 확인을 유지한다. 하단 저장도 공통 버튼으로 처리하고 본문 여백을 20px로 맞췄다.
- 설정 저장 버튼/미저장·저장 중·완료 상태를 화면 하단에 고정한다. 설명은 읽기 쉬운 크기와 행간으로 정리했다.
- 뉴스 제목/설명 글자와 행간을 키웠다. 검색 행동·문의 종류·기업 탐색 탭은 좁을 때 줄바꿈한다. 페이지 이동의 비활성도 시각적으로 구분한다.
- 키워드 삭제 영역은 최소 44×44px과 삭제할 키워드의 접근성 이름을 갖춘다. 긴 키워드는 닫기 영역을 남기고 줄바꿈한다.
- Toast의 고정 340px 폭을 화면 폭−32px(최대 440px)로 바꾸고, 제목/본문을 읽을 수 있는 크기·행간으로 표시한다. 색깔 띠 없이 중앙 정렬하며 메시지 줄 수로 내용을 잘라내지 않는다.
- 상단 브랜드 이름은 글자 확대 시 남은 공간을 기준으로 축소 배치하고 한 줄로 표시한다. 실제 기기의 글자 크기 설정을 끄거나 제한하지 않는다.

## 확인 범위

앱 TypeScript / ESLint(캐시 없이 실행) / Expo 웹 export, 기존 대비·기기별 알림 해제·네이티브 의존성 테스트 7개를 확인했다.

격리된 앱 웹 미리보기 320×720에서 첫 자산 등록의 저장 버튼(x=20, 폭 280px, y=652), 뉴스 기간 시트 진입/적용, 설정 수정→저장 중→완료/비활성 상태, 라이트/다크 표시를 확인했다. 테스트 설정 요청은 지연시켜 진행 상태도 관찰한다. 실제 계정/투자/알림 등록은 건드리지 않는다.

글자 1.3배의 웹 근사 fixture로 설정·뉴스 버튼 줄을 점검했다. 이 과정에서 고정 340px Toast가 320px 화면 밖으로 나가는 문제를 찾아 수정했다. 근사 fixture는 Android 시스템 fontScale과 동일하지 않다.

실제 Android 키보드·TalkBack·OS 글자 확대, 실제 Google/푸시 및 처음 쓰는 이용자의 발견성 테스트는 미완료다. 다음 APK에서 검증하며 README APK 1.0.5에는 이번 수정이 아직 포함되지 않는다.
