# 게임·기업 상세·알림 조작 보완

사용자 APK 1.0.4 제보 후속. 기존 Issue #62 / WEB-38 / APP-21 안에서 진행하며 APK 자동 빌드를 실행하지 않는다.

## 화면 변경

- 게임 규칙을 6개 제목·문단으로 분리. Android 스크롤 시 제목/닫기는 고정한다. 웹도 같은 규칙을 사용한다.
- 동작 없는 세 단계 안내를 제거. 난이도와 게임머니, 공매도 스위치는 시작 전에 바로 노출한다. `?` 버튼에 공매도 손익과 모형의 한계를 설명한다. 별도 기능이 없는 ‘시작 설정’은 제거한다.
- 기업 상세에서 관심 등록/해제를 한 번 눌러 처리. 저장 중 재입력을 막고 실패하면 이전 상태를 유지한다. 상세 화면은 해제 후에도 유지한다.
- Android 차트 터치·좌우 이동에 정확한 가격과 KST 시각을 표시한다. 현재 시세와 과거 지점 가격은 구분한다.
- 시장 뉴스에 ‘외부 브라우저로 이동’/‘새 탭에서 열림’을 계속 표시한다. 읽을 때마다 확인 모달을 요구하지 않는다.
- 공통 모바일 메시지의 왼쪽 색 선을 없애고 중앙 정렬·여러 줄을 허용한다.

## 알림 계약과 운영

- 브리핑 수신 시간은 KST 기준 1~3개. 같은 일일 브리핑을 여러 시간에 받는 설정이며 매번 새 AI 분석을 생성하지 않는다. 늦은 폴링에 여러 시간을 놓쳤으면 한 번으로 묶어 발송하고 해당 시간들을 처리한다.
- 기존 단일 `pushTime` API와 기본 08:00는 유지한다. 새 설정 저장 시 `pushTimes`를 사용한다. 구형 클라이언트가 `pushTime`만 저장하면 단일 시간으로 돌아간다.
- 새 소식은 기본 끔. 관심 키워드 필요. 활성화 시각 이후 수집한 기사 중 제목/본문이 키워드와 일치하는 것만 묶는다. 키워드 일치가 투자 영향이나 추천 근거를 뜻하지는 않는다.
- 새 소식은 한 시간에 한 번 이하. 이미 발송 시도한 기사 ID는 최근 200개를 보관해 중복을 막는다. 24시간보다 오래된 발행 기사는 제외한다. 한 번에 최신 수집 구간 최대 50개씩 확인하며 스케줄러 폴링·수집 주기에 따라 늦을 수 있다. 모든 뉴스를 즉시 전달하는 서비스가 아니다.
- 새 여러 시간 설정은 시간별 1회 시도. 새 소식도 실패한 묶음을 매 폴링마다 재전송하지 않는다. 발송 결과는 기존 푸시 감사 기록에 남는다. 기존 단일 시간 발송 동작은 호환을 위해 유지한다.
- 브리핑과 새 소식 발송은 한 Render 프로세스에서 공통 잠금으로 직렬화한다. 여러 서버 인스턴스 운영 시 DB 기반 선점이 추가로 필요하다.
- 해제는 확인창 없이 이 기기의 Expo 토큰 또는 이 브라우저의 endpoint만 제거한다. 다른 기기·관심 기록·수신 시간은 유지한다. 이미 제공처가 수락한 알림은 회수하지 못한다. OS의 권한 자체를 변경하지는 않는다.
- 기존 등록 APK의 로컬 토큰이 없으면 기존 권한이 허용된 기기의 Expo 토큰을 조회해 제거한다. 새 등록부터 토큰은 SecureStore에 저장한다. 키·토큰은 문서/로그에 출력하지 않는다.
- 서버가 아직 새 API를 지원하지 않으면 설정 저장·해제를 성공으로 표시하지 않고 서버 업데이트 안내를 보여준다.
- H2/PostgreSQL 스키마에 컬럼만 추가한다. 기존 기록 삭제·초기화 없음. Render 최신 코드 배포가 필요하다.

## 검증과 한계

모바일 45회귀·타입/lint, 웹 타입/build/lint, 기존 백엔드 전체 테스트 통과. 새 정책 4개 테스트에서 기기별 제거/다른 기기 보존, 시간 중복/늦은 폴링/다음 날짜, 입력 검증, 새 기사 선택/한 시간 제한/중복/실패 재시도 방지를 확인했다. 최종 CI에서 PostgreSQL 통합 검사를 실행한다.

격리 데이터로 390px 모바일 규칙 줄바꿈·닫기, 원터치 관심 등록/해제 후 상세 유지, 차트 터치 ₩200,000 및 날짜 표시, 중앙 메시지, 게임 시작 난이도·버튼이 화면에 들어오는 배치를 확인했다. 웹에서 08:00+12:00와 새 소식 동시 저장, 1366×768 시작 조건과 공매도 설명을 확인했다. 운영 사용자 기록에는 쓰지 않았다.

실제 Android DateTimePicker·터치/키보드·TalkBack·푸시 수신은 별도 확인이다. 공개 APK 1.0.4는 이번 후속 이전 코드이므로 이번 변경은 아직 설치본에 포함되지 않았다. 다음 APK는 사용자 요청 후 만든다.
