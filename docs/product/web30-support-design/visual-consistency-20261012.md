# 주요 화면의 시각·조작 기준 정리

사용자 ‘정리 한번 해줘’ 요청과 README 설치본을 통한 통합 테스트 요청 후속. 기존 WEB-38/APP-21/Issue #62에서 진행한다.

- 웹·Android 상단을 단일 테마 버튼으로 통일. 라이트에서는 달, 다크에서는 해를 표시하며 목적지를 버튼명으로 안내한다. 44px 터치 영역·기기 저장·저장 중 중복 입력 방지 유지.
- 모바일 주요 버튼에 공통 48px 최소 높이, 12px 모서리, 눌림/비활성/진행 표시를 적용. 게임 시작/주문/다음 턴과 기업 등록/관심 토글, 설정 저장을 정리한다. 새로운 애니메이션이나 임의 퍼센트는 만들지 않는다.
- 반복되는 화면 제목 카드·작은 분류 제목을 제거하고 제목/설명만 남긴다. 게임 시작 화면도 큰 외곽 카드를 덜어내고 화면 기준선에 맞춘다. 본문·보조 설명은 제목보다 작게 유지한다.
- 게임 주문 총액과 확인 버튼은 하단에 고정한다. 주문 처리 중 전체 내용을 가리던 오버레이를 제거하고 버튼에 진행 표시를 남긴다. 기존 확인·실패·중복 주문 방지 로직은 유지한다.
- Android 수신 시간은 ‘추가’ → 시각 선택·확정으로 추가한다. 선택한 시각을 다시 ‘추가’하던 중복 단계를 없앤다. iOS는 선택 후 완료 시 추가한다. 1~3개 제한과 서버 저장은 그대로 유지한다.
- 설정의 저장 상태를 화면에 남긴다. 변경 없으면 버튼을 비활성화하고, 저장 후 다시 편집하면 미저장 상태로 표시한다. 처리 중 새 편집이 있더라도 실제 제출한 값만 저장 기준으로 삼는다.

## 검증

모바일 48회귀·타입/lint 및 웹 타입/build/lint 통과. 웹에는 기존 웹 푸시 effect 경고 1개가 있다. 격리 360×800 화면에서 테마 전환·재실행 저장 복원, 설정 저장/다시 편집 상태, 게임 시작 버튼 배치, 주문 수량 1→3에 따른 고정 총액 22,495.54→67,486.62를 확인했다. 미리보기 실행 오류 없음. 실제 Android 키보드·글꼴 확대·DateTimePicker·로그인/푸시 검증은 설치 후 별도다.

이번 설치본은 1.0.5/versionCode10으로 준비한다. PR #98의 규칙·차트 터치 가격/시각·알림 설정과 이번 화면 정리를 같은 설치본에 포함한다. 로컬 Expo prebuild+Gradle로 만들며 EAS 클라우드 요청을 보내지 않는다. 기존 서명·APK 파일·다운로드 링크 확인 후 README를 바꾼다. 이후 자동/추가 APK 빌드는 활성화하지 않는다.
