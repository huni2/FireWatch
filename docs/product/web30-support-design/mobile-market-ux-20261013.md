# Android 버튼 대비·시장 소식 후속 (2026-10-13)

기존 APP-21/WEB-38 · Issue#62 안에서 처리한다. 새 과제·추가 APK/AAB/EAS/OTA 요청은 만들지 않는다. **공개 설치본1.0.6/빌드11에는 아래 소스 변경이 포함되지 않는다.**

## 변경

- 주요 버튼/선택 탭은 두 모드 모두 밝은 오렌지 `#FFC49B`와 짙은 글자 `#17202E`를 쓴다. 링크/본문의 브랜드 색과 별도로 관리한다. 버튼 배경은 항상 스타일 객체로 전달하고 Android 누름 효과는 ripple로 처리한다. 로딩 글자/아이콘은 같은 전경색을 유지하고 비활성은 읽히는 보조 색을 쓴다.
- 시작·다음 턴·등록·저장·동의·재시도·기업/차트 선택·운영자 등록의 같은 색 역할을 정리했다. 기존 onAccent/onbrand 조합은 앱 컨트롤에서 제거했다.
- 브리핑의 이름만 있는 칩을 `기업명 · 관심 추가/해제` 버튼으로 바꿨다. 누른 기업에 처리 표시·중복 클릭 차단·성공/실패 안내를 제공한다. 현재 목록을 읽고 정확한 이름/단일 결과만 등록하며 다른 기업을 임의로 고르지 않는다. 이미 등록된 기업도 같은 곳에서 해제한다.
- 저장 성공 시 활성 관심 목록과 브리핑이 갱신된다. 숨은 탭의 갱신 조회는 멈추고 다시 열 때 현재 목록을 읽는다. 설정 화면의 미저장 입력을 다른 화면의 변경으로 덮어쓰지 않는다.
- 마지막 관심 기업을 해제해도 selected를 차트 탭에 합쳐 다시 표시하던 동작을 없앴다. 관심 목록에서는 마지막까지 비울 수 있고, 별도의 기업 상세를 읽는 경우만 상세를 유지한다. 처리 중 다른 삭제 클릭과 저장 실패의 무응답도 보완했다.
- 시장 브리핑 본문은 BottomSheetScrollView로 바꿨다. 제목/닫기는 고정하며 본문과 마지막 관심 버튼까지 스크롤한다. Android 손가락 스크롤은 실제 설치 확인이 남아 있다.
- 시장 지표는 주가지수/환율/원자재·채권에서 지표를 선택하고7/30일 저장 이력 그래프를 확인한다. 기존 `/api/briefings?from=&to=`를 사용하며 서버/수집/DB 변경과 추가 외부 조회가 없다. 기간 변경은 가져온30일 자료 안에서 처리한다.
- 날짜/값 포인터, 값 범위에 맞춘 세로축, 원래 관측값을 유지한 툴팁을 제공한다. 수집이 없는 값·날짜는 임의로 채우지 않고0/1개 기록과 실패를 구분한다. 날짜는 브리핑 저장 기준이며 확정 종가나 실시간 값으로 소개하지 않는다.
