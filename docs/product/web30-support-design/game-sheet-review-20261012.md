# APK 게임 시작·시트 후속 개선 (2026-10-12)

기존 #62 과제에 연결한 APK 이용자 피드백이다. 새 과제를 파생하지 않는다.

- 투자 연습 시작을 설정 아래의 스크롤 영역에서 화면 하단 고정 영역으로 이동했다. 난이도·공매도 설정은 스크롤하되 시작은 언제든 보인다. 초기 상태 조회와 중복 시작 차단은 유지한다.
- 게임 시작·거래 확인·다음 주·자산 상세 매수·결과 공개 버튼을 테마의 잉크/표면 색으로 처리해 대비를 확보한다. 시작 중에도 색을 흐리게 만들지 않고 진행 표시와 설명을 보여준다.
- AppSheet를 규칙·주문·순위·결과·자산 상세·턴 복기에 적용했다. 기존 설치된 bottom-sheet 라이브러리를 사용해 새 의존성을 추가하지 않았다.
- 공통 손잡이, 오른쪽 닫기, 본문 스크롤, 반투명 바깥 영역, 250ms 열기/닫기를 공유한다. 시스템 모션 감소 설정은 라이브러리 기본 동작을 따른다.
- 손잡이를 아래로 끌면 닫힌다. 본문 스크롤은 닫기 제스처와 분리했다. 바깥 영역·닫기 버튼·Android 뒤로가기로도 닫을 수 있다.
- 주문/순위 처리 중에는 손잡이·바깥 영역·닫기·뒤로가기를 차단한다. 진행 도중 닫기 애니메이션과 상태가 겹치면 시트를 다시 연다. 주문 총액과 확인 버튼은 키보드를 고려한 하단 영역에 유지한다.
- BottomSheet 콘텐츠의 접근성 그룹화를 해제해 제목·본문·닫기 버튼이 각각 탐색되도록 했다. 손잡이는 한국어로 설명한다.

## 검증과 한계

앱 TypeScript와 ESLint(캐시 없이 실행), Expo 웹 export를 확인했다. 360×800의 격리된 앱 웹 미리보기에서 시작 버튼은 x=20/y=675.2/폭 320/높이 48px, 바탕 rgb(23,32,46)/글자 흰색이었다. 규칙 본문 스크롤 시 유지, 손잡이 아래 드래그 시 닫힘, 순위 시트 진입을 확인했다.

미리보기는 테스트 데이터와 대체 로그인/동의 상태를 사용한다. 운영 계정의 투자·순위 기록은 변경하지 않았다. 실제 Android 기기의 터치·키보드·TalkBack 확인은 APK 테스트에 남는다. 이번 요청으로 APK를 빌드하지 않으며 README 1.0.5 설치 파일에도 아직 포함되지 않는다.
