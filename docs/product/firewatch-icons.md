# FireWatch 전용 메뉴 아이콘

2026-10-08. 공용 Ant Design 아이콘을 전용 벡터로 교체했다. 운영체제 이모지나 외부 아이콘 묶음을 가져온 것이 아니라 프로젝트 안에서 SVG 경로를 직접 작성했다. 이미지 생성 도구로 비트맵을 생성하지 않았다.

## 형태와 사용

32×32 좌표, 둥근 선 끝·모서리, 선 두께2.2, 길게 뻗은 불씨와 둥근 바닥을 공통 서명으로 사용한다. 기록·회사·뉴스·게임·계정·설정·도움말 등 기존20종과 게임 행동·결과9종, 총29종이다. 기능의 익숙한 형태와 작은 불꽃 포인트를 조합했다. 실제 메뉴에는20~24px로 표시하고 모바일 주요4탭은22px다.

색은 공유 디자인 토큰의 본문색/오렌지를 사용한다. 웹 다크에서는 현재 테마색을 따른다. 아이콘만으로 주요 메뉴 뜻을 전달하지 않고 이름을 함께 표시한다. 상단 계정/설정/도움말은 좁은 웹에서 아이콘으로 표시하되 접근 가능한 이름과 hover/focus 설명을 유지한다. 앱 상단 버튼도 접근 가능한 이름·기존 행동을 유지한다. 장식용 SVG를 스크린리더에서 제외하며 선택/비활성/포커스와44px 터치 영역은 그대로다.

## 원본과 적용 위치

- `shared/firewatch-icons.ts` — 웹·앱이 공유하는29종 SVG 경로 원본.
- `shared/assets/firewatch-game-icons.svg` — 게임9종의40px/20px 비교판. 시작·다음 턴·선택·결과·매수·매도·초기화·주의·안내.
- `shared/assets/firewatch-menu-icons.svg` — 전체20종의40px/24px 비교판. 실제 메뉴는 비교판 이미지를 다운받지 않는다.
- `web/src/components/FirewatchIcon.tsx` — DOM SVG. AppShell의 주요 메뉴·계정 도구·더보기·다크 모드와 GameMenu의5도구에 사용한다.
- `mobile/src/components/FirewatchIcon.tsx` — 기존 react-native-svg로 같은 원본 렌더링. HomeScreen 주요4탭·설정/도움말과 PracticeMenu에 사용한다.

추가 이미지 다운로드·서버 호출·새 라이브러리 설치가 없다. 게임 행동/턴 결과/주의·실패 안내/빈 상태/순위 등록 메시지에도 전용 벡터를 적용했다. 주 버튼의 아이콘은 현재 글자색 단색으로 대비를 맞춘다. 표준 로딩·입력 펼치기·창 닫기는 유지한다. 추천·분야/뉴스·브리핑 등의 보조 탭은 밀도를 위해 텍스트를 유지한다.
