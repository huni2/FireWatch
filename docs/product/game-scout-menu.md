# 게임 로비·마스코트 메뉴

2026-10-08 사용자 피드백 반영. 시작 화면은 제목·짧은 설명·자체 생성한 정찰대 이미지 하나·게임 시작 버튼으로 구성한다. 시작 자금과 공매도 설정은 접힌 ‘시작 설정’에서 조정한다. 가상 자료라는 안내는 접지 않는다.

웹은 이미지에 마우스를 올리거나 클릭하면 순위·규칙과 설명을 보여준다. 키보드 ArrowDown으로 열고 Escape로 닫는다. 터치 화면도 클릭으로 열린다. 플레이 중에는 같은 이미지가 작은 메뉴가 되어 기록 등록·복기·종료를 제공한다. 등록/복기는 가능한 기록이 있을 때만 활성화하며 종료는 확인을 거친다.

Android는 같은 이미지를 눌러 설명이 있는 하단 메뉴를 연다. 닫기·바깥 영역·Android 뒤로 가기로 닫을 수 있다. 시스템 이모지를 새 메뉴 장식으로 사용하지 않는다. 기본 라이트 모드와 가상투자가 독립 연습 메뉴라는 제품 범위를 유지한다.

버튼은 전체 폭을 채우지 않고 내용에 맞춘다. 시작·주문 확인·다음 턴은 최소 높이44px로 터치 영역을 확보한다. 웹 노트북은 시장 피드가 스크롤되는 동안 우측 주문·진행 버튼이 고정된다. 주문 초기화와 체결 장부/가상 가격 규칙은 그대로다.

## 검증

- 웹 build 성공, lint 오류0(기존 설정 effect 경고2).
- 브라우저 fixture: 노트북5해상도, 모바일3폭, 다크·종료, 픽→주문 선택→총액→체결→다음 턴→복기, 초기화 장부 보존, 외부 시세 요청0.
- 새 로비: 1366/1920/360/390px·다크, 이미지 로드, 짧은44px 버튼, hover/터치, 규칙, 키보드 열기/닫기, 시작 자금 선택과 시작 실패 후 재시도 가능 상태.
- 모바일 타입/lint 및 Android export 성공, PNG 포함 확인. 실제 설치에서 메뉴·폰트 확대·키보드는 APP-21 확인 항목이다.
- 시험은 API를 fixture로 대체한다. 운영 계정의 주문·게임 종료·순위 등록을 실행하지 않는다.

공개 배포/CI 확인은 `llm-wiki/log.md`에 기록한다. 이미지 출처와 생성 프롬프트는 `shared/assets/firewatch-lobby-scout.prompt.md`에 보관한다.
