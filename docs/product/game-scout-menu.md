# 게임 로비와 개별 도구

2026-10-08 사용자 피드백 반영. 마스코트는 중앙 장식이며 메뉴 버튼이 아니다. 순위와 규칙은 각각 작은 버튼으로 바로 연다. 플레이 중에도 순위·규칙·기록 등록·복기·종료를 개별 버튼으로 제공한다. 웹은 아이콘과 짧은 이름, hover/키보드 focus 설명을 제공한다. 터치와 Android에서는 누르면 해당 화면이 바로 열린다. 등록/복기는 기록이 있을 때만 활성화하고 종료는 확인을 거친다.

시작 화면은 제목·짧은 설명·정찰대 이미지 하나·개별 도구·게임 시작 버튼으로 구성한다. 시작 자금과 공매도 설정은 접힌 ‘시작 설정’에서 조정하며 가상 자료 안내는 계속 표시한다. 버튼은 내용에 맞춘 폭과 최소44px 높이를 유지한다. 웹 노트북의 시장 피드 스크롤·우측 주문 고정, 주문 초기화·체결 장부와 가격 규칙은 유지한다.

이전 ‘마스코트 하나를 누르는 통합 메뉴’ 구현은 사용자가 기능 구분이 불분명하다고 지적해 교체했다. 이미지 생성 프롬프트는 shared/assets/firewatch-lobby-scout.prompt.md에 보관한다.

## 공통 메뉴

- 웹: 내 계정·설정·도움말을 상단 개별 링크로 제공. 작은 화면은 접근성 이름이 있는44px 아이콘으로 표시. 더보기는 공지·문의/관리와 화면 설정을 제공한다. 일반 사용자에게 감사로그를 표시하지 않는다. 모바일 폭에서 다크 전환은 더보기 안에 둔다.
- Android: 8개 가로 메뉴를 ‘내 기록/기업 탐색/시장 소식/게임’ 4개 주요 탭과 해당 화면의3개 보조 탭으로 구성. 기업→시세·관련 뉴스 이동과 푸시→브리핑 탭 전환을 보존한다. 설정의 이모지 버튼을 텍스트로 바꾸고 웹 이용안내를 여는 도움말을 별도로 제공한다.

## 검증과 한계

웹 build/lint 오류0(기존 설정 effect 경고2), 모바일 타입/lint·Android export 성공. API를 fixture로 대체한 로비/분리 도구/공통 메뉴/키보드/모바일 폭/다크·익명 운영 메뉴 숨김과 주문·초기화·체결·다음 턴·복기 검증을 진행한다. 공개 배포와 최종 확인은 llm-wiki/log.md에 기록한다. 운영 게임/순위를 시험용으로 쓰지 않는다.

이번 개별 버튼·공통 메뉴 변경은 이전3855eac/versionCode3 APK 소스에 포함되지 않는다. 실제 설치 확인은 APP-21에 보존한다.
