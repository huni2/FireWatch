# 게임 주문 입력·작업 바 정리

2026-10-08 사용자 피드백: 게임 바가 복잡하고 거래 주문을 초기화할 기본 동작이 없다.

웹 상단은 게임 이름·현재 턴·가상 날짜와 게임 메뉴/종료로 나눈다. 순위·기록 등록·규칙·지난 턴 복기는 게임 메뉴에서 접근한다. 시장 피드의 별도 순위 홍보 패널은 제거한다. 거래 주문 아래 고정 영역은 총액과 체결 확인, 그 아래는 다음 턴이다. 주문 상세의 중복 총액은 제거한다.

웹과 모바일 주문 초기화는 미체결 입력만 지운다. 개별 종목 선택 상태에서 회사와 수량을 비우고 매수 방향으로 돌아간다. 확인 가격·오류·선택 안내·요청 ID와 미리보기 세대를 초기화해 이전 비동기 응답이 새 주문으로 사용되지 않게 한다. 초기화는 서버 거래를 호출하지 않으며 현금·보유량·체결·턴을 바꾸지 않는다. 진행 중 요청 및 웹 주문 확인 대화상자에서는 초기화 버튼을 막는다. 모바일 네이티브 확인창은 화면 상호작용을 차단한다.

웹 브라우저 fixture로 매도/수량9/픽 선택→초기화→빈 회사·빈 수량·체결 비활성, 픽 재선택→수량1→매수, 체결·다음 턴 후 초기화의 장부 보존을 확인했다. 1280×720/1366×768/1440×900/1536×864/1920×1080에서 다음 버튼과 주문 영역 고정, 360/390/768px와 다크·종료 검증도 통과했다. 게임 메뉴에서 규칙과 순위 접근·선택 공개/철회 회귀를 확인했다. 외부 가격/미리보기 요청0(가상 게임), 운영 시험 거래0.

웹 build/lint, 모바일 타입/lint 통과. 네이티브 실제 설치 화면·초기화는 새 APK에서 확인해야 한다.
