# 투자 메모와 복기 — 첫 확장

2026-10-17. 웹·Android 공통 구현. 자산 등록 입력 단계는 늘리지 않는다.

## 사용 흐름

1. 등록한 보유 자산의 ‘투자 메모’를 누른다.
2. 보유 이유, 다음 확인할 내용, 재점검 날짜를 선택적으로 적는다.
3. 다음 방문에서 재점검 날짜가 된 메모를 먼저 보고, ‘돌아본 내용’에 확인한 점을 적는다.
4. 점검을 마쳤다면 날짜를 다음 날짜로 바꾸거나 지운다. 날짜만으로 알림을 보내거나 자료를 자동 판정하지 않는다.

메모는 현재 값을 수정·보관한다. 수정 전 메모의 버전별 이력이나 매매 일지는 이번 범위에 포함하지 않는다. CSV 내보내기와 계좌별 자산 구분도 후속 후보로 둔다.

## 저장과 보존

- `PUT /api/portfolio/note`: 현재 포트폴리오 버전과 종목코드, 메모 필드만 보낸다. 수량·현금·시세·평균 구매 가격·점검 기준은 변경하지 않는다.
- `portfolios.holding_notes_json` nullable TEXT 열을 추가한다. 기존 행을 초기화하거나 기존 보유 JSON 형식을 바꾸지 않는다.
- 기존 앱이 보유 수량이나 계획을 저장해도 메모는 유지된다. 오래된 버전의 메모 저장은409로 거절하고 화면 입력을 유지한다.
- 보유 기록을 삭제한 종목의 메모는 ‘이전 보유’로 계속 조회·수정할 수 있다. 메모 삭제는 확인 후 별도로 수행한다. 연결된 계정의 포트폴리오 삭제 시 함께 삭제된다. 익명 기기 원본·백업의 기존 삭제 범위는 개인정보처리방침을 따른다.
- 기기/계정 기록 합치기에서는 메모 개수를 표시하고, 중복 메모는 사용자가 선택한 계정/기기 우선순위를 따른다. 기기 원본은 보존한다. 이전 보유 메모만 있는 기기도 묵시적으로 버리지 않는다.
- 보유 이유·다음 확인은 각각500자, 돌아본 내용은1,000자, 종목별 메모는 이전 보유를 포함해100개까지다. 기존 메모를 자동으로 삭제해 한도를 맞추지 않는다.
- 날짜는2000~2100년의 실제 날짜만 허용하며 앱의 재점검 상태는 한국 날짜를 기준으로 표시한다.
- 메모 본문은 감사로그·AI 분석·공개 순위에 전달하지 않는다. 서버 요청/응답의 문자열 요약에서 본문을 숨기며, 기존 데이터 보안 안내에 선택적 메모 항목을 추가했다.

## UI와 호환성

- 웹은 공통 Drawer, Android는 키보드 대응·고정 저장 버튼이 있는 기존 입력 화면을 사용한다. 작성 중 닫기는 확인하고 저장 실패 후 입력을 유지한다.
- 메모가 없으면 자산의 ‘투자 메모’ 버튼에서 시작한다. 목록은 재점검 날짜 도래 순으로 먼저 세 개를 보여주고 펼칠 수 있다.
- 목록의 날짜도 요일을 함께 표시하고, 날짜를 정하지 않은 메모는 ‘날짜 없이 보관 중’으로 안내한다. 재점검 개수는 ‘N개 메모를 다시 확인해보세요’로 표시하며 돌아본 내용도 목록에서 미리 볼 수 있다.
- 기존 메모의 모든 항목을 비우면 저장 버튼을 ‘메모 삭제 확인’으로 바꾸고 삭제 확인을 거친다. 확인을 취소하거나 삭제 요청이 실패하면 서버 메모를 유지한다.
- `holdingNotes`가 없는 이전 서버 응답에서는 메모 기능을 표시하지 않는다. 새 서버·웹·Android 테스트 배포를 구분한다.
- 유료 서비스·새 외부 데이터 소스·광고·추가 분석 SDK·정기 수집 작업을 도입하지 않았다.

## 검증과 배포 상태

- 백엔드 전체240개:239개 통과, 기존 PostgreSQL 전용 검사1개 스킵. 메모 보존·조회·수정·삭제·충돌·사용자 격리·입력 제한·본문 감사로그 비노출과 계정 연결 우선순위·계정 삭제를 확인했다.
- 공통 메모/등록/점검 검사22개와 모바일 기존 회귀84개 통과. 웹 빌드·타입·린트 및 모바일 타입·린트를 확인했다. 웹 린트의 기존 웹푸시 경고1개는 별도다.
- 리뷰 보완: Android 달력에 전달할 날짜의 공백을 제거하고, 빈 값·잘못된 날짜는 한국 오늘 날짜로 대체한다. 공백·윤년·범위 경계·한국 자정 경계의 회귀 검사와 웹·모바일 타입 검사를 확인했다. 선택 입력 안내는 두 화면 모두 ‘모든 항목’으로 수정했다.
- 달력 UI 보완: 날짜 직접 입력과 별도 달력 버튼을 하나의 날짜 선택 영역으로 정리했다. 선택한 날짜는 `2026. 10. 24. (토)`처럼 표시하고 옆의 ‘지우기’로 해제한다. Android는 기본 달력, 웹은 기존 Ant Design의 한국어 달력을 사용한다. 웹 달력은 작은 화면에 맞는 크기를 사용하며 Esc로 달력만 닫을 수 있다. ‘이 날짜에 앱에서 다시 확인해요. 알림은 보내지 않아요.’로 안내한다.
- 출시 전 화면 보완: 웹·Android 상단에 ‘보유 내역 보기’를 추가하고 저장 완료 안내를 점검 내용보다 먼저 배치했다. Android의 자산 추가·현금 계획도 상단에서 바로 연다. 점검 항목은 먼저 두 개, 지난 기록·비중 변화는 각각 세 개를 보여주고 나머지는 펼쳐 본다. 공통 분석 결과를 잘라 버리지 않아 네 번째 점검과 네 개 이상의 비중 변화도 확인할 수 있다.
- 검색·등록 보완: 삼성전자·애플·TIGER 검색 예시를 누르면 실제 검색을 수행한다. 검색어 지우기, ‘1/2 종목 선택 → 2/2 수량 입력’ 안내를 제공하며 Android에서도 선택 후 수량 칸으로 초점을 옮긴다.
