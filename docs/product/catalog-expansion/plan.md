# 기업 시작 목록 확대 BE-32

BE-22의 전체 시장 수입에 앞서 공식 IR/소개 자료로 확인한 기업12개를 기존14개에 추가한다. 웹·앱 분야별 목록과 서버 검색이 같은 원본을 사용한다. ETF5개는 그대로 유지한다.

카카오·SK하이닉스·기아·현대모비스와 AMD·브로드컴·알파벳 Class A·아마존·어도비·GM·뱅크오브아메리카·화이자를 추가한다. 전체 시장·추천·실시간 시세라고 표시하지 않는다. 출처 확인일은 기업별로 유지하고 기존 항목을 새로 확인한 것으로 처리하지 않는다.

시드 중복/필드/출처/날짜 오류를 생성 전 차단한다. 서버 재시작에서 신규 검색 반영·멱등성·최신 외부 메타데이터와 기존 시세 보존을 검증한다. 외부 시세 요청·수집 예산 확대·OpenSearch·APK 빌드는 수행하지 않는다. 코드 검증 뒤 Issue/PR로 리뷰하고 배포는 머지 후 확인한다.
