# 게임 그래프 조회 API 선행 작업

BE-28의 필요한 그래프만 조회하는 서버 계약을 BE-35로 구현한다. 웹/앱은 기존 계약을 계속 사용하며 서버 배포 확인 후 별도 연결한다. 이번 작업만으로 운영 턴 속도 개선을 주장하지 않는다.

- 모든 턴 응답 API에 compact=true 선택을 추가한다. 기본은 전체 그래프, compact는 자산별 현재/직전 두 점으로 등락 표시를 보존한다. 원장·평가·픽·규칙은 동일하다.
- 기기 소유 세션·선택 자산·확정된 턴 기준 상세 그래프 GET을 추가한다. 종료/이전 시뮬레이션도 저장 버전으로 재현하며 타기기·미래 턴·없는 종목을 거절한다. 거래 원장/시세/뉴스 외부 호출과 데이터 삭제는 없다.
- 기존 출력 고정 회귀, 압축 전 응답 크기, 실제 HTTP·DB 동작을 검증한다. Issue/PR/CI/머지 기록을 남긴다. Render 반영과 웹/앱 연결, 실제 운영 지연은 BE-28 후속이다. APK 요청0.
