# 결정과 관찰

2026-10-09. 모든 턴에 전체34자산×최대24점이 포함된다. 클라이언트 목록은 직전 두 점으로 등락을 계산하고 상세 모달은 전체 그래프를 사용한다. 따라서 기존 출력은 기본값으로 보존하고 compact는2점, 상세는세션/턴/자산으로 조회한다. 서버 배포 전 클라이언트를 먼저 바꾸지 않는다. 별도 게임 버전·분리 순위는 만들지 않는다.

Issue#15 등록. 상세는 읽기 전용 조회로 턴 진행의 쓰기 잠금을 잡지 않는다. 선택형 compact는 전체 가격/원장/픽/등락에 필요한 두 점을 보존한다. 첫 HTTP 비교에서 가상 Briefing.createdAt의 응답별 생성 시각 차이로 실패했으며 저장 게임 필드와 구분해 그 필드만 비교에서 제외한다. 기존 규칙/가격 출력 고정 검사는 통과했다.
