# 운영 게임 검증 계획

BE-28의 실제 26기업·픽 주문·compact/선택 상세 확인을 테스트 전용 무작위 기기의 한 게임으로 검증한다. 기존 사용자 기기/세션·계정·순위·수집 데이터는 건드리지 않는다. 시험 원장은 삭제하지 않고 종료 상태로 보관한다.

한 번에 한 요청, 총60회 이하·요청 timeout30초·자동 재시도 없음으로 제한한다. 거래 요청 ID와 예상 턴/가격을 사용한다. 한국 클라이언트에서 관측한 HTTP 시간·본문 크기와 시작/거래/다음 턴/현재 조회/그래프의 작은 표본을 기록한다. 이 값은 DB 독립 처리 시간이나 서비스 SLA/p95가 아니다.

전 시장 수입과 서버 페이지 탐색은 BE-22의 데이터 출처·갱신 설계에 의존한다. 26기업 게임의 운영 검증과 전 시장 확대 완료를 구분한다. Android/EAS/APK 빌드는 요청하지 않는다.

1. 실행 명시·격리 기기·요청 한도·실패 중단을 갖춘 검증 스크립트와 로컬 안전 회귀를 작성한다.
2. GitHub Issue에 범위와 완료 기준을 기록하고 운영 한 게임을 검증한다.
3. 실제 수치와 남은 경계를 문서·과제에 반영하고 PR/CI/머지로 완료 기록을 남긴다.
