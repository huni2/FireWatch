# 결정과 관찰

실제 검증은 테스트 전용 무작위 기기 한 개와 한 게임에 한정한다. 기존 사용자의 식별자/세션을 입력받지 않는다. 기본 실행은 쓰기 플래그가 없으면 네트워크 전에 거절한다. 보고서에는 기기 식별자를 싣지 않고 별도 로컬 private 파일로 보관한다. 실패 시 자동 반복/정리 삭제를 수행하지 않는다. 운영 데이터 삭제 금지와 APK 보류를 유지한다.

HTTP 시간은 네트워크·서버·DB를 합친 한국 클라이언트 관측이다. 작은 표본에 p95/SLA나 DB 실행 시간을 주장하지 않는다. 전체 시장 수입 BE-22와 구분하고 BE-28의 미검증 항목을 정직하게 남긴다.
