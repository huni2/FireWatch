## 확인한 병목과 수정

기존 histories는 각 턴의 가격을 매번 시작 가격부터 재계산했다. 마지막 턴은 자산당 누적 가격 변동 276회를 처리했다. 수정은 반올림 전 값을 이어 계산해 23회로 줄인다. symbol 조회도 Map으로 변경했다. 저장된 시드, 날짜, 가격, 거래정지와 과거 평가 의미는 유지한다. 5개 시드 × 모든 자산 × 모든 턴의 독립 가격 평가와 일치하는 회귀 검사를 추가했다.

로컬 JVM 워밍업 100회, 번갈아 9개 배치 × 200회, 배치 중앙값: 13개 자산 마지막 턴 그래프 구성 0.2201195ms → 0.054256ms. 원래 방식은 각 턴에서 price를 호출하는 경로로 재현했다. 운영 Render 성능이나 DB·HTTP 지연 측정이 아니다. 마이크로벤치마크 소스/결과는 이번 작업의 로컬 검증 자료에 보관했다.

## 확대 설계

- 실제 기업 마스터(회사명·업종·시장)는 가상 가격 시뮬레이션과 분리한다. 전체 국내 상장사 목록은 출처·갱신일·사용 조건을 확인하고 수집한다.
- 검색·분야 탐색은 페이지 단위로 표시한다. 전 종목 카드/차트를 한번에 렌더링하지 않는다.
- 턴 응답은 보유 종목·이번 픽·주문 종목의 현재 가격과 손익에 집중한다. 탐색 가격은 페이지 단위, 과거 그래프는 상세 조회로 요청한다.
- 시드와 종목 ID로 과거 가격을 재현한다. 기존 게임은 버전별 종목 목록·이벤트 규칙을 보존한다. 목록 변경으로 거래정지/픽의 난수 결과가 바뀌는 문제를 먼저 해결한다.
- 실제 회사명을 쓰더라도 모든 게임 가격·뉴스·사건·픽에 가상 표시를 유지한다. 실제 공시·뉴스와 섞지 않는다.
- 장기 현실감: 랜덤 날짜 대신 순서가 있는 게임 날짜, 업종별 영향, 변동성·유동성 차이를 별도 게임 버전으로 설계한다. 기존 기록에 소급하지 않는다.
