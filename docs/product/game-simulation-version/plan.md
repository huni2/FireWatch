# BE-33 게임 규칙 버전 보존

기업 목록을 곧바로 바꾸면 같은 시드의 거래정지 대상과 픽이 달라져 기존 게임 결과가 바뀐다. BE-28을 기존 게임 버전 보존과 새 기업/조회 계약 단계로 나눈다.

이번 단계는 기존 행과 신규 세션을 버전1로 명시하고 모든 서버 게임 연산을 저장 버전에 연결한다. 미지원 버전은 규칙1로 대체하지 않고 변경 전에 거절한다. 과거 실제 자료 세션은 기존 경로를 유지하고 응답 버전은 null이다.

H2/PostgreSQL 비파괴 컬럼 추가와 반복 실행, 기존5시드24턴 결과의 고정 해시, 거래/턴/종료/랭킹 거절을 검증한다. API에는 추가 필드 simulationVersion을 제공한다. UI/게임 자산 수/난수 규칙은 바꾸지 않는다. APK 빌드는 보류한다.
