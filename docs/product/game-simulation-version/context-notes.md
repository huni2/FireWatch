# 작업 결정

현재 GameSimulation의 assets5개와 난수 선택을 그대로 고정한다. 현재 클라이언트는 공유5종목과 모든 그래프를 사용하므로 버전2를 먼저 켜면 픽 직접 매수와 이름 표시가 깨진다. 버전2 활성화는 클라이언트 조회 계약·순위 구분까지 함께 구현할 때 진행한다.

시드 null인 과거 게임은 버전1 컬럼값을 받더라도 실제 자료 경로를 유지한다. 기록 삭제·덮어쓰기·실제 운영 게임 생성은 하지 않는다.

변경 전 기준 SHA-256은 41bf972c8a5b97ced825d9088526cd4fc853f88edaa1b34b6a541e365c68554b. 5시드·24턴·13자산 가격/그래프/날짜/뉴스/픽/변동 근거를 포함한다. 로컬 PostgreSQL은 설치하지 않고 기존 전용 CI DB에서 이전을 검증한다.
전체177검사 중 신규 API 테스트가 잘못된 /next 경로로 실패했다. 실제 /next-turn으로 수정해 회귀를 재실행한다. 구현 실패와 테스트 작성 오류를 구분한다.

게임 관련 회귀 재실행 성공. API가 DB 저장 버전1을 읽고 매수/다음 턴 가격을 유지하며, 미지원999 종료 거절 후 상태/턴/체결을 보존함을 검증했다. PostgreSQL 검사는 CI 대기다.
