# 게임 그래프 클라이언트 연결

WEB-40/APP-32. Render 새 상세 경로의 기기별404 응답 확인. 기존 API404와 구분해 서버 반영을 확인했지만 운영 게임을 생성하지 않았다.

웹/앱의 모든 턴 요청에 compact=true를 사용하고 상세보기는 선택한 세션/턴/자산의 전체 그래프 GET으로 연결한다. 두 점짜리 요약을 전체 그래프로 표시하지 않는다. 상세 로딩·명시적 재시도·화면 내 최대32개 캐시·닫힘/빠른 선택 변경 뒤 이전 응답 무시를 구현한다. 가격/원장/주문 입력은 그래프 실패에도 보존한다.

4폭 브라우저 fixture와 지연/실패/캐시/새 턴 회귀, 웹 build/lint·앱 타입/lint·CI·PR·웹 배포를 검증한다. 서버/게임 규칙·운영 기록은 변경하지 않는다. APK/EAS0, 운영 지연 측정과 실기기는 별도다.
