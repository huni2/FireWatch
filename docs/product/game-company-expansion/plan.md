# 출시 전 단일26기업 게임

사용자 확정에 따라 출시 전에는 게임 하나·순위 하나를 제공한다. 이전5기업 시험 세션은 새 게임 시작 시 종료 상태로 보관하며 거래/날짜/가격을 삭제하거나 새 가격으로 덮어쓰지 않는다. 이전 시험 세션을 플레이하거나 순위 재등록하는 선택지는 제공하지 않는다.

공식 출처가 확인된26기업의 이름/분야/별칭/확인일을 고정 JSON으로 복사한다. 게임용 기준 가격을 사용하며 기업 실제 공시처럼 가상 계약을 쓰지 않고 업종 시나리오 뉴스를 만든다. 서버 기업 메타데이터로 픽/주문/보유/복기를 연결한다. 웹/앱은 검색·분야 필터·6개씩 표시한다.

BE-34는 서버 단일 게임·기록 보관·가격/픽/턴·응답 크기와 계산 시간을 검증한다. WEB-37은 웹 흐름/반응형, APP-30은 Android 화면/타입/lint/로컬 export다. 기존 순위와 주간 우승자 계약은 유지한다. 시즌은 출시 이후 별도 과제다.

26기업은 시작 범위이며 전 시장 카탈로그·수천 기업 페이지/상세 그래프 API는 BE-28 후속이다. 기존 규칙의 고정 해시는 기록 보존 회귀에 유지한다. CI 후 PR 머지하고 배포 반영을 구분한다. APK 빌드는 하지 않는다.
