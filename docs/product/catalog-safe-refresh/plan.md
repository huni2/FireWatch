# BE-43 공식 회사 정보의 안전한 갱신

BE-22의 후속으로 검토한 공식 스냅샷을 배포할 때 이름·업종 변경을 반영한다. 자동 수집 스케줄은 추가하지 않는다. GitHub Issue/PR에서 스냅샷 차이를 검토하고 다음 날짜 자료를 배포한다.

DB에 마지막 공식 적용값을 별도로 보관한다. 현재 회사 정보와 검색 필드가 그 값과 일치할 때만 다음 날짜 자료로 갱신한다. 기존 편집·더 최신 자료·출처를 확인할 수 없는 행·편집 카탈로그는 보존한다. 최초 도입에서는 현재 스냅샷과 완전히 일치하는 행만 기준값을 설정한다. 원본 누락을 상장폐지로 판정하거나 삭제하지 않는다. 시세·보유·게임 기록은 변경하지 않는다.

검증은 기존 스키마 반복 적용, 신규/반복/날짜 역행/동일 날짜 변경/이름·업종 갱신/편집·분류·시세 보존과 실제 PostgreSQL CI를 포함한다. APK/EAS 빌드는 진행하지 않는다.
