# 설계 근거

기존 수입은 없는 코드만 추가하므로 공식 회사 이름이 바뀌어도 DB에는 이전 이름이 남았다. verified_at 날짜만으로 덮어쓰면 운영자 편집을 잃을 수 있다. 따라서 마지막 공식 적용값을 기준으로 현재 행의 모든 검색/분류/메타데이터 필드를 대조하고 조건부 UPDATE를 수행한다.

최초 도입에서 이미 다른 내용으로 편집된 행은 공식 기준값을 추측하지 않는다. 충돌 항목은 보존하고 집계 로그를 남긴다. 스냅샷 누락·시장 이동은 자동 삭제나 보유 코드 이전의 근거가 아니다. 기존 큐레이션 갱신 정책은 이번 범위에서 변경하지 않는다.
