# 첫 행동과 색의 역할 — 2026-10-11

사용자 승인: 전체 디자인 리뷰에서 지적한 설명·중복 메뉴·기본 컴포넌트 반복을 줄이고 색을 역할에 따라 확장한다. 기존 WEB-38 / Issue #62에서 처리하며 새 과제 번호와 APK/EAS 빌드는 만들지 않는다.

## 실제 변경

- 웹 헤더는 네 주요 메뉴와 계정 메뉴 하나로 압축한다. 계정 메뉴에 계정·설정·도움말·테마·공지/의견·단기 관찰·별도 회사 시세 검색을 제공한다. 운영자 감사 접근 조건은 유지한다. 시장 소식의 뉴스/브리핑/지표 하위 이동은 유지한다.
- 빈 홈은 `내 자산`과 첫 등록을 중심으로 구성한다. 모바일에서는 큰 가상 예시를 숨기고 별도 예시 모달로 읽는다. PC는 등록 행동 옆에 상품/시장 관계 예시를 둔다. 예시는 개인 기록에 저장하지 않는다.
- 보유 행의 삭제는 더보기로 옮기고 기존 확인·실패 처리와 수정 초점 복귀를 유지한다.
- 투자 연결 지도는 실제 등록 분류를 가운데 묶음과 연결된 보유 노드로 표현한다. 동일 입력 지수와 실제 ETF 구성 기업은 구분한다. 선의 굵기로 자산 비중을 암시하지 않는다.
- 기업 탐색은 질문형 제목과 설명·하위 메뉴를 줄이고 검색/추천/분야별 기업을 우선 배치한다. 목록의 선정 이유는 세 줄까지 보이고 상세에서 전문을 읽는다. 위험은 펼침, 근거와 개인 보유 비교는 유지한다. 새 시세 요청이나 추정 가격은 추가하지 않는다.
- 뉴스 기본 제목은 `시장 소식`, 검색 조건이 있을 때 해당 조건의 관련 소식으로 표시한다. 모바일 검색은 키보드 검색으로 제출한다. 날짜 필터·페이지·오류/재시도·시각 기준은 보존한다.
- 게임 로비는 시장 읽기→선택→돌아보기의 24주 경험과 시작 행동을 먼저 보여준다. PC 캐릭터는 작은 보조 이미지, 모바일 웹/Android 로비는 큰 캐릭터를 제거한다. 순위와 규칙은 별도 도구이며 주문 고정·게임 원장·완주 등록 계약은 그대로다.
- Android는 짧은 홈·뉴스 제목, 추천 목록 밀도, 실제 보유 연결의 세로 관계, 게임 진행 소개와 캐릭터 축소 방향을 반영한다. 설치/TalkBack 성공으로 주장하지 않는다.

## 색

| 역할 | 라이트 | 다크 | 의미 |
|---|---|---|---|
| 주요 행동 | 기존 브랜드 주황 | 기존 브랜드 주황 | 등록·시작·주문 |
| 자산 연결 | #176E65 / #EAF4F0 | #8AD5C6 / #192E2C | 보유 분류·연결·ETF |
| 시장 근거 | #2C527F / #ECF1F8 | #9BBFE9 / #1C2A3E | 뉴스·분석 출처·개별주식 |
| 보조 정보 | 기존 중립 색 | 기존 중립 색 | 시각·통화·현금 |

색만으로 정보를 전달하지 않는다. 연결 기준·노드 이름·비중·본문·단계 번호를 함께 표시한다. 시장 근거의 남색을 수익률/손실 상태에 적용하지 않는다. Android는 현재 기본 라이트 색으로 반영한다.

## 검증

웹 build/lint, Android type/lint 성공(기존 웹 푸시 effect 경고 1개 유지). 공유 투자 연결/날짜 경계 5검사 통과. 시험 API로 7개 화면×7개 폭 및 다크 5화면, 연결 기준·기간 검증·등록/취소·하단 메뉴·가로 넘침 확인. 주간 게임 4폭의 필터·주문 초기화·종료/선택 공개 회귀 통과. 로비 3폭의 단계·개별 순위/규칙·삭제 확인 취소·계정 메뉴·테마 접근 확인.

실제 Chromium 200% 확대에서 등록·오류·취소/수정·초점 복귀 확인. 깨끗한 닫기 뒤 초점은 다음 프레임에 돌아오므로 보조 검사를 초점 복귀 완료를 기다리도록 수정했다. 제품의 시간 제한을 늘리거나 초점 복귀 검사를 제거하지 않았다. 검색 라벨은 화면에서 숨기되 접근성 이름은 유지하며 검사는 해당 이름으로 키보드 초점을 확인한다.

가상 API의 레이아웃 검증은 실제 사람의 선호·운영 데이터 분석 품질·Android 설치 검증을 대신하지 않는다. CI·머지·웹 배포 근거는 기존 context에 추가한다.
