# 첫 자산 등록과 저장 후 점검

2026-10-08. BE-31/WEB-33/APP-28. 홈의 긴 입력 폼을 별도 등록/수정 화면으로 분리한다. 회사 검색과 수량만으로 등록하고 매입가는 선택 입력한다. 웹은 오른쪽 패널, Android는 키보드를 고려한 전체 화면을 쓴다. 투자 계획 편집도 별도 화면으로 분리한다.

매입가 미입력은 null로 보존하며 원금/손익을 계산하지 않는다. 비중은 수집 시세와 환율로 평가 가능한 자산 및 현금 기준으로 계산하고 포함/제외 범위를 표시한다. 전체 평가액은 일부 가격이 없을 때 확정하지 않는다. 기존 숫자 매입가 JSON과 낙관적 버전 충돌/저장 이력은 유지한다. 데이터 초기화나 외부 시험 주문은 하지 않는다.

저장 응답을 즉시 점검 화면에 반영한다. 저장 실패/버전 충돌 시 입력은 유지하고 최신 기록과 덮어쓰기를 구분한다. 기존 자산 삭제·현금/계획 변경 기능은 유지한다.

이번 단계는 등록→홈 연결이다. 종목 상세와 게임의 추가 구조 개편은 후속 단계다.
