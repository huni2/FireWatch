# APK 버튼 글씨 정렬·차트 선택 해제

APK 1.0.8에서 ‘등록하고 점검하기’, ‘관심 기업에 담기’ 글씨가 가운데에 오지 않는다는 제보와 차트 밖을 눌러도 가격 표시가 남는다는 제보를 반영했다.

공통 ActionButton은 busy=false일 때도 처리 표시 공간을 글씨 왼쪽에 두고 있었다. 오른쪽에도 같은 폭의 비상호작용 공간을 둬 정상·처리 중·아이콘 상태에서 글씨 중심을 유지한다. 두 화면의 개별 스타일로 우회하지 않는다.

종목과 시장 지표 차트는 터치한 가격을 유지하되 바깥 터치로 선택을 해제한다. 공통 선택 컨텍스트는 현재 선택한 차트만 초기화한다. 차트 내부 터치는 전파를 멈춰 읽기를 유지하며, 다른 화면·모달 터치는 선택을 닫는다. 라이브러리 내부 포인터만 초기화하기 위해 해당 LineChart를 다시 마운트한다. 데이터 훅과 조회 결과는 유지한다. 종목·기간·지표가 바뀌면 포인터도 초기화한다.

## 검증

모바일 71개 회귀·타입·변경 파일 lint 통과. 기존 버튼 검사 18개에 처리 슬롯의 좌우 폭 대칭과 오른쪽 공간의 비상호작용 검증을 추가했다.

격리된 React Native 웹 터치 미리보기 390×844의 라이트·다크에서 두 버튼 글씨 중심 오차 0px, 종목·시장 지표 가격 선택→바깥 터치 해제→재선택, 해제 시 시세 재조회 없음, JS 오류 0을 확인했다. [측정 기록](button-chart-dismiss-20261013.json). 네이티브 입력 취소 확인창은 웹에서 검증하지 않았고 실제 Android 터치는 미확인이다.

현재 공개 APK 1.0.8에는 이 후속 소스가 포함되지 않는다. 이번 제보로 추가 APK/EAS/OTA 빌드를 실행하지 않았으며 다음 명시적 빌드 요청에 포함한다. 기존 과제 #62에 기록한다.

사용자 후속 최신화 요청으로 이 수정은 APK 1.0.9/빌드14에 포함했다. 위 미포함 안내는 당시 1.0.8 기준이다. [파일 검증](android-109-build.json). 실제 Android 확인은 미완료다.
