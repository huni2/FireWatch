# Android 게임 규칙 하단 스크롤

APK 1.0.7에서 게임 규칙의 아래 내용을 읽을 수 없다는 사용자 제보를 확인했다.

PracticeRules는 AppSheet 안에서 일반 React Native ScrollView를 사용하고 스크롤 영역의 높이를 명시하지 않았다. 바텀시트 전용 BottomSheetScrollView로 바꾸고 flex: 1과 마지막 문단 아래 여백 48을 적용했다. 규칙 내용과 상단 닫기 버튼, 손잡이 닫기 동작은 유지한다.

모바일 타입 검사와 해당 파일 lint, diff 공백 검사는 통과했다. 실제 Android에서 마지막 ‘기존 게임 기록’ 문단까지 스크롤한 뒤 위로 돌아오고, 손잡이 및 닫기 버튼으로 종료할 수 있는지는 다음 설치본에서 확인해야 한다. 현재 공개 APK 1.0.7에는 포함되지 않는다. APK/EAS/OTA는 이번 제보만으로 새로 실행하지 않는다.
