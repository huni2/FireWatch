# APK 모달·가독성·처리 상태 점검

## 변경

- 공지, 기업 상세, 브리핑, 뉴스 기간, 게임 규칙·순위·복기·자산 상세·결과·주문의 긴 본문 10곳에 AppSheetScrollView를 적용했다. 높이는 flex: 1로 제한하고 마지막 문단 아래 여백을 둔다. 상단 닫기와 결과·주문 하단 행동은 스크롤 밖에 둔다.
- 주문 수량·순위 닉네임은 Android에서 바텀시트 전용 입력을 사용한다. 시트는 키보드 높이에 대응하고 닫힐 때 포커스를 정리한다. 웹 미리보기는 네이티브 포커스 API가 없어 일반 입력으로 대체한다. 개인정보 전체 화면도 스크롤 높이를 제한했다.
- 순위 버튼에 공통 ActionButton의 색상·비활성·처리 상태를 적용했다. 키워드 입력 글자도 테마 글자색을 명시했다. 라이트·다크의 주요/다음/보조 버튼은 기존의 밝은 배경·짙은 행동 글씨 원칙을 유지한다.
- 관심 기업 저장과 순위 등록·철회는 상태 렌더링 전에 ref로 잠근다. 관심 해제는 서버 성공 전 항목을 지우지 않고 누른 삭제 위치에 처리 표시를 남긴다. 실패하면 기존 기록을 유지한다. 게임 시작·주문·다음 턴은 기존 operation 잠금과 버튼 처리 표시를 점검했다.

## 검증과 한계

모바일 71개 회귀 검사, 타입·변경 파일 lint·출시 설정·diff 공백 검사 통과. 공통 버튼의 양쪽 모드 정상/비활성/처리 중 18개 검사는 실제 렌더 속성 대비 4.5:1 이상을 확인했다.

격리된 React Native 웹 미리보기 390×740에서 라이트·다크 규칙 마지막 문단 도달, 고정 닫기·다시 열기, 순위 닫기, 주문 입력과 하단 행동 노출, 관심 해제의 제자리 처리 표시와 추가/해제 요청 각각 1회를 확인했다. JS 오류는 없었다. 이 결과는 실제 Android 키보드·제스처·로그인·푸시 검증이 아니다.

이번 사용자는 1~4 단계와 새 APK 1회 빌드를 승인했다. 설치본은 1.0.8/versionCode 13으로 준비하며, 공개 파일 검증 후 README 링크를 바꾼다. 실제 휴대폰 로그인·푸시·관심 목록·24주 완주는 설치 후 확인해야 한다. 기존 과제 #62를 유지하며 자동/EAS/OTA 빌드는 켜지 않는다.
