# 최신 Android 설치본 준비

2026-10-11 추가 설치 피드백: 시작 화면 이상·강제 종료·구형 앱 이미지. APK 빌드는 금지 상태다. 기존 Android 아이콘/스플래시가 구형 파일을 참조함을 확인했으며 현재 웹 불꽃 브랜드를 앱용 안전 영역에 맞춰 렌더링한다. 시작 전 빈 화면, 동의 읽기/저장 Promise 실패 및 반복 탭 처리를 보완하고 JS 렌더 오류의 복구 화면을 제공한다. 네이티브 프로세스 강제 종료는 종료 순간·Android 로그 없이는 원인 확정/해결 완료로 표시하지 않는다. 앱 타입·lint·로컬 번들, 시작/동의 미리보기와 이미지 검증을 수행해 기존 Issue #62에 기록한다. EAS/APK/새 릴리스는 생성하지 않는다.

2026-10-11 설치본 확인 후 사용자 피드백: 명시적으로 요청하기 전 APK 빌드 금지. 최초 동의의 개인정보 전문, 앱 도움말·투자 정보 안내는 앱 내부로 이동한다. 동의 전에는 기존 동의 상태와 체크 여부를 유지하는 네이티브 모달에서 전문을 읽고 Android 뒤로가기로 복귀한다. 개인정보 전문은 웹·앱 공통 자료로 유지하며 앱 설정에서도 다시 열 수 있게 한다. 기사 원문·공식 상품 설명은 외부 출처 링크로 유지한다. 소스·타입·lint·웹 빌드 및 동의 전 부작용 경계를 확인하고 Issue #62/PR에 기록한다. EAS 빌드·APK 교체는 실행하지 않는다.

2026-10-11 사용자 요청으로 최신 APK 빌드 보류를 이번 1회 해제한다. 기존 WEB-38/Issue #62 범위에서 최신 main의 Android UI를 포함한 1.0.1 설치본을 만든다. 기존 빌드 상태·무료 사용량 확인 → 버전 증가 → 타입·린트·설정 검사 → preview 1회 빌드 → APK 다운로드·SHA-256 확인 → GitHub 사전 릴리스와 README 설치 링크 갱신 순서로 진행한다. 실제 기기 설치·로그인·푸시는 빌드 성공과 구분한다.

APP-21의 최신 소스 설치 검증을 위해 versionCode5 preview APK를 만든다. 커스텀 메뉴/게임 아이콘과 분리된 자산 등록 화면을 포함한다. 기존 versionCode4는 빌드 완료됐지만 이 변경을 포함하지 않는다.

무료 EAS 한도와 비용을 확인하고 타입·린트·출시 설정·Android 번들을 검증한 뒤 한 번만 빌드한다. 실제 로그인·푸시 수신·TalkBack·키보드 검증은 설치 기기 결과가 있어야 완료로 표시한다. Play 제출은 별도다.
