# 최신 Android 설치본 준비

2026-10-11 사용자 요청으로 최신 APK 빌드 보류를 이번 1회 해제한다. 기존 WEB-38/Issue #62 범위에서 최신 main의 Android UI를 포함한 1.0.1 설치본을 만든다. 기존 빌드 상태·무료 사용량 확인 → 버전 증가 → 타입·린트·설정 검사 → preview 1회 빌드 → APK 다운로드·SHA-256 확인 → GitHub 사전 릴리스와 README 설치 링크 갱신 순서로 진행한다. 실제 기기 설치·로그인·푸시는 빌드 성공과 구분한다.

APP-21의 최신 소스 설치 검증을 위해 versionCode5 preview APK를 만든다. 커스텀 메뉴/게임 아이콘과 분리된 자산 등록 화면을 포함한다. 기존 versionCode4는 빌드 완료됐지만 이 변경을 포함하지 않는다.

무료 EAS 한도와 비용을 확인하고 타입·린트·출시 설정·Android 번들을 검증한 뒤 한 번만 빌드한다. 실제 로그인·푸시 수신·TalkBack·키보드 검증은 설치 기기 결과가 있어야 완료로 표시한다. Play 제출은 별도다.
