# 한국어 초성으로 회사 찾기

기업 탐색과 종목 검색의 기존 입력창에서 `ㅅㅅㅈㅈ`를 입력하면 삼성전자, `ㅋㅋㅇ`를 입력하면 카카오를 찾는다. 웹과 Android가 같은 서버 검색을 사용하므로 이 기능을 위해 새 APK를 만들 필요는 없다.

- 초성만 입력한 검색을 지원한다. `삼ㅅ`처럼 완성형 글자와 초성을 섞은 입력은 기존 이름·별칭 검색을 따른다.
- 국가·상품 종류·분야 필터와 최대50개씩 페이지 이동을 함께 사용할 수 있다. 짧은 초성은 여러 회사를 찾을 수 있다.
- 현재 저장된 회사명에서 검색 값을 만든다. 서버 시작 시 없는 값과 달라진 값만 보완하며, 이 작업으로 회사 설명·분류·시세·투자 기록을 변경하지 않는다.
- 검색 결과가 있다는 것은 가격이 수집됐다는 뜻이 아니다. 미수집 시세는 기존과 같이 빈 값으로 제공한다.

## 배포 확인

Render에 PR#36의 서버 변경을 배포해야 한다. 추가 환경변수는 없다. 다음 공개 조회에서 삼성전자와 카카오가 포함되는지 확인한다.

```text
GET /api/catalog?q=ㅅㅅㅈㅈ
GET /api/catalog?q=ㅋㅋㅇ
GET /api/stocks/search?q=ㅅㅅㅈㅈ
```

전체 카탈로그2669개·ETF5개, 기존 이름 검색, 분야·국가 필터와 페이지 사이 중복 없음도 함께 대조한다. 운영 조회 결과는 배포 확인이며 동시 부하 성능이나 모든 DB 행의 보존 증거로 확대하지 않는다.
