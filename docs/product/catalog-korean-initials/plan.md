# 한국어 기업 초성 검색

BE-42는 BE-22의 한국어 검색 후속이다. 회사 이름의 초성을 저장해 ㅅㅅㅈㅈ 같은 입력으로 기업을 찾는다. 순수 초성 입력만 별도 경로로 처리하고 기존 이름·별칭·코드·업종 검색과 필터/페이지 계약은 유지한다.

기존 DB에 검색용 name_initials 열을 추가한다. 현재 DB의 name으로 계산하므로 편집된 회사 이름도 보존한다. 부족하거나 달라진 검색 값만 묶음 업데이트하고 이름 동시 변경은 WHERE 조건으로 보호한다. 시세·투자/게임 기록·회사 분류를 수정/삭제하지 않는다. 기존 DB·반복 시작·이름 변경·검색·페이지 경계를 H2/PostgreSQL로 확인하고 실제 운영 확인은 배포 후 진행한다. 앱 재빌드 없이 공통 서버 API에서 제공한다.
