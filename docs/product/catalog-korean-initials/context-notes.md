# 설계 근거

InstrumentCatalog는 이름/별칭/업종의 정규화된 search_text 부분 일치만 지원했다. 초성은 현재 회사 이름을 기준으로 별도 name_initials에 저장해 기존 편집·별칭 검색 문자열을 덮어쓰지 않는다. 초성19개 문자로만 이루어진 입력을 지원하며 완성형 한글/영어가 섞인 입력은 기존 검색 경로를 따른다.

초성 값이 비어 있는 기존 DB와 새 행을 시작 시 한 번 조회해 필요한 항목만250개씩 갱신한다. 업데이트는 읽은 name이 그대로일 때만 수행하며 기존 시세·분류/설명·검증일·투자 기록은 변경하지 않는다. 이 값은 회사 분야 분류나 추천 신호가 아니다. 부분 일치 검색 성능은 실제 규모 검사로 확인하며 대규모 부하 성능으로 주장하지 않는다. APK/EAS 빌드0.
