# KRX 상장법인 검색 목록 확대

BE-22의 한국 기업 목록을 KIND의 시장별 상장법인 다운로드로 확대한다. KOSPI/KOSDAQ 법인 목록이며 우선주·ETF·코넥스·미국 전 시장을 포함했다고 표시하지 않는다. 공식 원본/확인 날짜·해시·행수·출처를 함께 보관하고 가격/추천을 생성하지 않는다.

다운로드 HTML 표를 EUC-KR로 읽어 이름·시장·종목코드·업종을 검증한다. 새 영숫자6자리 코드도 보존한다. 임의 분야를 추정하지 않고 unclassified로 구분한다. 원본 전체에서 필수 항목/중복/시장/코드/예상 범위를 검증한 뒤 JSON을 생성한다.

서버는 기존 편집31개 메타데이터를 보존하고 directory의 없는 symbol만 묶음 INSERT한다. 종목 수만큼 개별 SELECT를 하지 않는다. 시세·투자/게임 기록을 바꾸거나 없는 종목을 삭제하지 않는다. 외부 수집은 Render 시작에서 실행하지 않는다. 재시작/반복 입력에서 기존 자료와 새 영숫자 종목·한국어 검색·시세 null/보존을 H2/전용 PostgreSQL로 검증한다.

일단 한국 법인 검색 범위 확장이 완료 기준이다. 분야별 편집26개 메뉴는 기존 출처 기반 목록이며 전 시장 분류로 바꾸지 않는다. 전체 해외/ETF·폐지/재상장 정기 갱신은 BE-22 후속에 남긴다. APK0.
