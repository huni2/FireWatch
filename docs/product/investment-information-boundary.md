# AI 분석과 투자 정보 이용안내

2026-10-07 사용자 요청: 실제 투자 손실을 고려해 AI 분석이 참고용이라는 사실을 제품 화면에 명시한다.

## 적용

- 웹·모바일 추천/단기 후보/브리핑/포트폴리오에는 `shared/investmentNotice.ts`의 일관된 안내를 사용한다. 매수·매도 지시 및 수익 보장이 아님, 원금 손실 가능성, AI 오류·누락, 지연 시세, 기준 시각·원문 확인, 과거 성과의 한계를 명시한다.
- `/investment-info`는 로그인 없이 열리고 웹 푸터와 도움말·모바일 안내에서 접근한다. 오류 신고 연락처도 제공한다.
- 가상 게임 자료와 실제 투자 자료를 구분한다. 게임 픽·뉴스·가격으로 실제 투자 판단을 해서는 안 된다고 안내한다.
- 법령상 이용자 권리를 제한하거나 제공자 책임을 일괄 배제하는 문구를 사용하지 않는다. 체크박스를 눌렀다는 이유만으로 책임이 면제된다고 주장하지 않는다.
- 수익 보장·확정 상승 같은 표현과 미확인 근거를 제품에 추가하지 않는다. 분석 당시 근거와 위험·날짜별 기록 보관은 유지한다.

## 제공 범위와 출시 전 검토

고지는 법적 책임이나 등록 의무를 자동으로 없애지 않는다. 금융위원회는 불특정 다수에 대한 개별성 없는 조언과 개인별 투자판단 제공을 구분한다. 현재 기간·성향 기반 구성 초안도 제공 실질을 검토해야 한다. 무료 여부만으로 법적 적용에서 제외된다고 판단하지 않는다. 개인별 매수·매도 지시, 유료 자문, 계좌 자동매매를 추가하기 전에 관련 등록·신고 범위를 전문가와 검토한다. 이번 변경은 법률 검토 완료나 책임 면제를 의미하지 않는다.

- [국가법령정보센터: 투자판단 제공 방식 관련 대법원 판례](https://law.go.kr/LSW/precInfoP.do?mode=0&precSeq=231803)

개인 포트폴리오의 신규 분석은 입력 자산의 비중·거래 통화·지수명 중복을 서술적으로 계산한다. ETF 구성 종목과 환헤지 상태를 추정하지 않는다. 환율 가정은 원금 환산 계산이며 수익 예측이 아니다.
