# 상품 목록 페이지 이동

WEB-41. 확대된 한국 법인 검색 목록을 웹에서도 첫50개 이후로 탐색할 수 있게 한다. 기존 서버의 page/total/hasMore 계약을 사용하고 서버·수집·APK 빌드는 변경하지 않는다.

검색/종류/국가 변경은 page0으로 동시에 초기화한다. 검색 입력은 제출 시에만 조회하고 지우기는 조건도 제거한다. 조회 중·실패·조건 변경 때 이전 응답을 새 결과처럼 표시하지 않는다. 상단/하단 이전·다음과 표시 범위를 제공하며 하단에서 이동하면 목록 처음으로 스크롤한다. 처음/마지막/빈 결과·실패 복구·응답 경쟁·작은 화면을 확인한다.
