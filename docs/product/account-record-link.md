# Google 연결 시 기기·계정 기록 비교 — 2026-10-14

기기에서 시험용 보유 기록을 삭제한 뒤 기존 Google 계정으로 연결하면, 빈 포트폴리오 행의 존재만으로 로그인까지 차단되던 문제를 수정한다. 관심 기업과 보유 기록이 서로 다른 경우에도 사용자가 처리 방법을 선택할 수 없던 흐름을 함께 보완한다. 새 과제를 파생하지 않는다.

## 사용자 흐름

- 보유 종목·현금이 없고 기기에만 있는 관심 기업도 없으면 기존 계정으로 바로 연결한다. 빈 저장 행은 충돌로 취급하지 않는다.
- 양쪽 기록이 다르면 Google 검증 후 기기/계정의 종목·수량·매입가·현금·관심 기업을 비교한다. 관심 기업 이름은 카탈로그에서 조회한다.
- ‘계정 기록만 사용’은 기기 기록을 합치지 않고 로그인한다. 기기 원본은 보존한다.
- ‘합치고, 중복은 계정 값 유지’는 새 종목과 관심 기업을 추가하고 중복 보유는 계정 값을 유지한다.
- ‘합치고, 중복은 기기 값으로 업데이트’는 중복 보유의 수량·매입가·분류를 기기 값으로 바꾼다. 두 수량을 더하지 않는다.
- 현금은 계정/기기 중 하나를 선택한다. 자동 합산하지 않는다. 목표·기간·성향·계좌 종류·월 추가금은 기존 계정 설정을 유지하며 계정에 포트폴리오가 없으면 기기 설정을 이어받는다.
- 관심 기업은 기업 식별자로 중복 제거해 합친다. 기기에 관심 기업만 있으면 두 가지 선택지만 표시하고 수량·현금 선택은 생략한다.
- 취소하면 연결도 기록 변경도 하지 않는다. 원본 기기 행과 포트폴리오·이력은 삭제하지 않는다. 연결 뒤에는 계정의 기록을 표시한다. 동일 기기에서 로그아웃해 다시 연결할 때 원본이 남아 있으면 비교가 다시 필요할 수 있다.

## 저장·검증

기존 `/api/auth/google/link`를 사용한다. 비교가 필요하면 `ACCOUNT_RECORD_CHOICE_REQUIRED`(409)의 `details.comparison`을 반환한다. 선택은 `recordChoice: { mode, cashSource, fingerprint }`로 같은 요청에 전달한다. 비교 내용은 Google 토큰 검증 후에만 제공하고 토큰은 클라이언트 메모리에서만 유지한다. 성공 응답 전에는 로그인 세션을 저장하지 않는다.

기기와 계정 설정/보유 행을 일정한 순서로 잠그고 최신 값으로 비교한다. 지문에는 양쪽 소유자·포트폴리오 버전·내용·관심 기업을 포함한다. 확인 사이 다른 기기가 수정하면 새 비교와 초기화된 선택을 요구한다. 선택 전 기록을 쓰지 않으며 병합·설정 저장·연결은 하나의 트랜잭션으로 처리한다. 계정 보유 변경 전후의 이력을 남긴다.

보유 50개·관심 기업 20개, 기존 금액·통화·ISA/연금·소수 자리 검증을 유지한다. 한도 초과는 미리 안내하고 합치기 확인을 막으며 서버에서도 다시 검사한다. 검증 실패로 일부 종목만 옮기거나 임의로 목록을 자르지 않는다. 푸시 등록·알림 시간·관심 키워드·가상게임은 이 선택으로 합치지 않는다. DB 스키마·환경변수 변경은 없다.

## 검증 범위와 배포

기존 계정/세션 통합 검사에 빈 기록, 관심 기업만 있는 경우, 비교·계정만 사용의 원본 보존, 두 중복 처리 방식과 현금, 오래된 지문, 관심/보유 한도와 계좌 규칙의 롤백, 연결 재요청을 추가했다. CI의 전용 PostgreSQL 검사에도 같은 클래스를 포함한다. 모바일 비교 계약 검사 3개를 추가했으며 모바일 전체 84개 검사·타입·린트를 확인한다.

360×740 라이트/다크의 앱 소스 브라우저 미리보기와 웹에서 선택 전 확인 버튼 비활성, 취소 후 재로그인 시도, 중복/현금 선택, 기록 변경 시 선택 초기화, 성공 후 닫힘과 화면 안의 고정 확인 버튼을 검사했다. Google 로그인·세션/API는 격리된 시험 대역이며 실제 Google/Android 로그인이나 운영 DB에 쓰지 않는다.

서버에는 최신 Render 배포가 필요하다. 웹은 최신 Pages 번들을 적용한다. 앱 소스는 수정했지만 APK/AAB를 이번 작업에서 빌드하지 않는다. 공개 APK 1.0.11/빌드16은 이 비교 화면을 포함하지 않는다. 빈 기록의 서버 차단 수정과 설치 앱의 새 비교 UI는 구분하며, 새 APK는 별도 사용자 요청 후 생성한다.
