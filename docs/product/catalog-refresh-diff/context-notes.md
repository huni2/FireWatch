# 현재 구현과 범위

BE-40의 서버 카탈로그는 없는 코드만 추가한다. 그러므로 새 snapshot에 회사명이 달라져도 기존 DB 회사명은 자동 업데이트되지 않는다. 변경 비교 보고서는 이 차이를 숨기지 않으며 missing을 상장폐지/삭제로 해석하지 않는다. 수정된 편집 자료 보존을 위해 자동 갱신을 무리하게 추가하지 않는다.

비교 기준은 검증된 원본 최소 필드와 시장별 symbol이다. 새 날짜만 바뀐 같은 회사는 unchanged에 포함한다. 이전 날짜 입력은 오류이며 새 파일을 저장하기 전에 확인한다. 독립 CLI는 읽기 전용이다. 개발 검증은 synthetic 변형을 사용하고 실제 shared/krx-companies.json과 서버 리소스를 변경하지 않는다.
