# 공식 기업 목록 갱신 비교

BE-41은 BE-22의 갱신 정책 후속이다. 검증된 두 KIND 스냅샷을 비교해 새 법인·이름 변경·업종 변경·원본에서 사라진 코드와 수량을 보여준다. 원본에서 사라진 항목은 상장폐지로 단정하거나 DB에서 삭제하지 않는다. 현재 서버의 추가만 하는 정책에 맞춰 변경/삭제 후보가 자동 반영되지 않음을 보고서에 명시한다.

원본 두 파일로 새 snapshot을 만들 때 기존 snapshot과 비교한 결과를 출력한 후 저장한다. 이전 날짜로의 입력은 저장 전에 거절한다. 독립 --diff 명령은 두 파일을 읽고 보고서만 출력한다. 날짜만 달라진 재확인은 필드 변경으로 집계하지 않는다. 기존 생성기의 시장·출처·인코딩·중복 검증을 재사용한다. 서버·실제 목록·DB·APK 빌드 변경 없음.
