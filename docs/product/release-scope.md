# 첫 출시 기능과 데이터 해석 범위

2026-10-08 기준. 제품의 중심은 저장된 시장 자료·분석 근거와 사용자가 직접 등록한 보유 구성의 연결이다. 가상게임은 독립 연습 메뉴다.

## 제공하는 정보

보유 수량·매입가·현금의 직접 기록, 매입원금 비중·단일 기업/분야/거래 통화 집중·입력 지수명 중복, 수집된 회사 가격·기준 시각·관련 기사와 날짜별 저장 추천 근거를 제공한다. 근거가 없는 과거 후보를 실제 추천 성과로 계산하지 않는다. 기사 문자열 일치는 관련성 탐색이며 가격 변동의 인과관계를 입증하지 않는다.

기간·성향에 따른 자산군 구성 초안과 월 배분은 고정 규칙 예시다. 개인별 적합성 심사·최적 포트폴리오·수익 예측이나 종목 매수 수량 권고로 소개하지 않는다. 무료 제공과 참고용 고지는 법률 검토나 책임 면제를 뜻하지 않는다. 개인별 권고 기능의 공개 제공 적법성 검토는 출시 전 확인 항목으로 남긴다. [투자 정보 이용안내](investment-information-boundary.md).

실제 주문/계좌 연동, 틱 실시간 가격, ETF 편입 종목/총비용/환헤지 자동 분석, 기업 전체를 아우르는 개인별 후보 점수와 매수·매도 지시를 제공하지 않는다. 상품 카탈로그는 출처를 확인한 시작 목록이며 전 시장 목록으로 광고하지 않는다. OpenSearch와 추가 유료 제공처는 도입하지 않는다.

## 수집 시점과 휴장일

- 한국 시간 07시 이후/16시 이후는 수집 슬롯이다. 모든 시장의 확정 종가 시각으로 표시하지 않는다. 미국 서머타임·휴장·시간외와 각 제공처의 regularMarketPrice 의미를 별도 검증하지 않은 가격을 확정 종가라고 부르지 않는다.
- 현재 금융 관측의 source_as_of=null은 제공처 기준 시각을 확보하지 못했다는 뜻이다. collected_at은 수집 시각이며 거래 체결/시장 마감 시각이 아니다. 실제 종목 기록은 제공처의 가격 포인트 시각과 수집 시각을 구분한다.
- 수출입은행 환율은 KST 전일부터 최대7일을 조회한다. 해당 기간 공휴일·장기 연휴로 값이 없으면 누락으로 남긴다. 오래된 값을 오늘의 환율로 다시 저장하거나 임의 생성하지 않는다.
- 거래소 공식 휴장 캘린더·확정 종가 수집은 이번 출시의 보장 기능에서 제외한다. 휴장에도 정기 수집은 제한 예산 안에서 진행할 수 있고, 이전 정상 자료를 보존한다. 이 정책은 자동 휴장 판단 구현이 아니다.
- 지수/금속은 항목별 실패를 격리한다. 핵심 항목 누락은 부분 실패로 기록하며 하루 실패3회 한도와 운영자 장애 알림을 유지한다. 선택형 한국 국채 누락은 다른 정상 지수를 지우지 않는다.

## 보관·복구와 출시 확인

[자료 보존·백업 절차](../deployment/data-preservation.md)를 따른다. CI의 별도 테스트 DB 복구 훈련, 실제 운영 백업 확보, 실제 기기 알림 수신을 서로 다른 확인으로 기록한다. 개인정보처리방침·계정 삭제·Play Data Safety의 실제 처리 대조와 출시 적법성 검토는 설치/제출 점검에 포함한다.

실제 기업명 기반 게임 확대는 버전별 가격/뉴스/사건/픽과 순위 공정성의 호환성을 먼저 확보해야 한다. 기존 게임을 새 목록으로 재해석하거나 기존 장부를 지우지 않는다. 현재는5개 가상 기업이다. 전체 기업 확대를 완료한 것으로 소개하지 않는다.
