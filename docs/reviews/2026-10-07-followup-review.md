# 2026-10-07 리뷰 과제 후속 결과.

웹은 Cloudflare Pages f2aa576a, 앱 코드 기준 서버는 Render baef209에 배포했다. GitHub Validate code 성공을 확인했다. 기존 production-review의 추천 공급·첫 입력·계정 세션·요청 지연 과제를 이번에 보강했다.

## 완료한 동작과 검증.

- 새 실제 추천 분석은 날짜·분석 시각·입력 브리핑·뉴스·종목별 이유·위험을 독립 저장한다. 오늘 수집된 원본 2개 후보 중 기사에서 해당 기업명을 확인한 1개만 노출한다. 다른 운용사 뉴스를 상장 증권사의 근거로 연결한 후보는 제외 사유를 표시하며 원본 JSON은 보존한다. 오늘 추천/날짜별 이력 200, 잘못된 날짜 범위 400, Gemini 실제 응답 감사로그 WARNING(시간 임계값 초과, 출력 생성 성공)을 확인했다. 제공 기사의 기업명 일치는 전체 내용 사실성이나 투자 성과를 보증하지 않는다.
- 첫 포트폴리오는 회사명·수량·매입가 중심으로 저장한다. 투자 조건과 자산 상세는 필요할 때 펼친다. 자산/현금이 없는 분석 카드는 숨긴다. 실제 카카오 검색·3주/35,000원 입력·KRW 저장·재조회 및 360px 가로 넘침 없음을 확인했다. ETF 분류/추종 지수 등 상세 편집은 유지한다.
- 연동 계정은 Google 검증 후 발급한 30일 기기별 Bearer 세션을 요구한다. 서버 해시 저장, 모바일 SecureStore, 재로그인·연결 기기 목록/해제·로그아웃·계정 삭제 시 전체 폐기를 추가했다. 만료/다른 기기 토큰/교체된 토큰 거부, UUID만 이용한 계정 접근/삭제 차단과 로그아웃 후 공유 자료 보존을 H2 실제 HTTP 통합 테스트로 확인했다. 세션 발급은 연결 행 잠금으로 직렬화한다. 네이티브 Google 왕복을 대신 검증한 것은 아니다.
- 게임/포트폴리오 단순 조회의 감사로그 쓰기, 빈 포트폴리오 뉴스/브리핑 조회와 중복 존재 확인을 줄였다. Server-Timing과 관리 키로 보호된 GET /api/operations/latency를 제공한다. 원시 기기 ID/종목/쿼리를 보관하지 않는 최대 256개 표본의 메모리 p50/p95이며 재시작하면 초기화한다. 무인증 지표 401, 관리 키 조회 200을 확인했다.
- HLB 검색이 같은 약칭의 해외 은행을 먼저 보여주던 문제는 국내 회사 별칭으로 정정했다. 운영 소문자 hlb 검색은 HLB/028300.KQ 한 건을 반환한다. 코드는 내부 식별자로 사용하고 화면에서는 회사 이름을 표시한다.

전체 백엔드 139개 테스트·웹 빌드·모바일 타입/린트·Android Hermes 번들 export가 통과했다. 웹 린트의 기존 설정 effect 경고 2개는 남아 있다. 별도 검증 기기로 주요 11개 웹 화면, 게임 픽 매수→다음 턴→주마등→자산 상세의 체결 그래프를 확인했다. 브라우저 예외/예상치 못한 API 실패/360px 가로 넘침은 없었다.

## 데이터와 속도.

배포 전후 기존 브리핑 45건·연결 뉴스 775건과 날짜 목록은 같다. 뉴스 보관함의 URL 중복 제거 건수는 654건에서 675건으로 증가했다. 기존 추천/브리핑/뉴스 삭제나 DB 초기화를 수행하지 않았다.

한 번의 운영 게임 API 측정은 시작 6.52초·체결 2.97초·다음 턴 1.82초였다. 장기 표본이나 콜드스타트 비교 실험이 아니므로 안정된 성능 향상율로 해석하지 않는다. 추천 조회는 표본 6개 기준 서버 p50 678ms·p95 2,359ms였다. DB 구간별 추적과 장기 지표는 아직 없고 무료 Render 콜드스타트도 남는다.

## 남은 출시·운영 확인.

실기기 Google 로그인/재시작/로그아웃/계정 삭제·SecureStore와 푸시 수신, 운영자 원래 브라우저에서의 복구/푸시 등록, 서명된 Android 출시 빌드·Play 스토어 제출은 미완료다. 이 로컬 환경에는 Android Google OAuth 공개 클라이언트 ID가 없으므로 해당 빌드는 로그인 준비 안내를 표시한다. 앱의 새 네이티브 빌드가 필요하다.

기기별 푸시 구독 폐기, 전체 종목/ETF 카탈로그와 실제 상품 비용·계좌 조건, 시장 휴장/미국 서머타임·확정 종가 및 백업/보관 정책은 후속 과제다. 설치 시 npm은 모바일 전체 의존성에 취약점 44건(critical 1건 포함)을 보고했다. 새 SecureStore의 취약점이라는 뜻은 아니며, 출시 전 의존성 감사와 호환성 검증이 필요하다. 자동 major 업그레이드를 하지 않았다.

정책: ADR 0019·0020. 보안 저장소 사용 근거는 [Expo SecureStore 공식 문서](https://docs.expo.dev/versions/latest/sdk/securestore/)이며 SDK 57 호환 패키지를 Expo 설치 도구로 선택했다. 기업·기사 혼동 검토에는 [미래에셋자산운용 공식 회사 소개](https://prod.investments.miraeasset.com/magi/company/innovation.do)와 [미래에셋증권 공식 글로벌 사업 소개](https://securities.miraeasset.com/newir/view/mobile/kr/business/global.jsp)를 참고했다. 이 소개만으로 모든 계열사 지분 관계를 자동 검증하지 않는다.
