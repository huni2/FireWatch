## 전체 판단

이전보다 첫 행동과 자료 설명은 명확해졌다. 기본 라이트/오렌지, 첫 자산 등록, 저장되지 않는 분석 예시, 뉴스 기간 선택, 추천 위험·근거 표시, 게임 주문 총액과 복기는 유지할 장점이다. 다만 현재 화면은 기능별 카드의 묶음에 가깝다. 추천을 본 뒤 기업의 가격·차트·뉴스·내 보유 영향을 이어서 확인하는 경험과 모바일의 우선순위가 아직 약하다. 새로운 컴포넌트를 많이 넣기보다 기능을 연결하고 첫 화면의 정보 순서를 바꾸는 쪽이 효과적이라는 디자인 판단이다.

## 유지할 점

- 메인의 첫 행동이 ‘첫 자산 등록하기’로 분명하고 샘플 분석은 실제 보유 기록과 구분된다. 실제 주문·증권사 자동 연동의 범위도 설명한다.
- 뉴스는 검색어와 오늘/7일을 먼저 선택하고 직접 날짜는 펼쳐 입력한다. 후보는 이유·위험·분석 시각·근거 기사로 판단 자료를 제공한다.
- 회사 이름으로 검색어를 전달하는 동선은 작동한다. `/stocks?q=카카오`에서 검색 입력에 카카오가 채워지는 것을 확인했다. 검색어 전달 자체가 끊긴 버그로 기록하면 안 된다.
- 게임은 실제 투자와 분리된 가상 회사·뉴스·가격을 사용하며 픽 선택이 주문에 연결된다. 주문 총액·체결 기록·턴 복기·자산별 그래프는 서비스의 차별점으로 키울 수 있다.
- 기본 라이트, 선택 다크, 홈 브랜드 링크, 도움말 재실행, 일반 사용자 감사로그 메뉴 제거는 유지한다. 게임 다음 턴 버튼 글자 대비는 라이트/다크 모두 현재 정상이다.

## 제품 흐름 제안

주요 이동: **내 기록 / 기업 탐색 / 시장 소식 / 게임**. 우측 상단: 계정 상태, 설정, 도움말, 운영자 전용 기능. 일반 투자 화면을 계정 메뉴에 숨기지 않는다. 모바일도 네 개의 주요 이동은 계속 보이게 한다. 계정 진입은 웹 Google 로그인 구현과 서버 역할 확인을 함께 진행해야 한다.

첫 방문은 목적 선택→결과 예시→첫 자산 입력→저장/분석→집중 비중과 관련 후보 확인으로 이어진다. 보유가 없는 사용자는 기업 탐색 또는 게임으로 갈 수 있어야 한다. 재방문 메인은 등록 소개보다 내 기록의 핵심 변화·자료 시각·다음 확인할 것을 먼저 보여준다.

기업 탐색은 회사 검색/분야 선택→기업 상세에서 가격·차트·뉴스·추천 근거 확인→관심 등록 또는 내 보유와 비교로 이어진다. 관심 등록은 조회의 필수 조건이 아니다. 추천이 1개이거나 없을 때도 검증 기준을 유지하고 탐색 동선을 제공한다. 화면을 채우기 위해 근거 없는 추천을 늘리지 않는다.

게임은 기본 조건으로 시작→첫 픽을 선택→총액 검토→체결→다음 턴→내 손익과 원인 복기로 이어진다. 보유/거래/기업 전체/뉴스를 동시에 긴 페이지에 펼치기보다 모바일 작업별 탭과 한 번의 명확한 주 행동을 제공한다. 실제 API 요청에 대한 피드백은 즉시 보여주되 연출 때문에 응답 표시를 지연하지 않는다.

## 추가 신뢰 문제

브리핑의 ‘선정 이력·가격 변화’에는 근거가 없는 과거 기록도 포함한다는 문구가 있다. 신규 사용자가 이를 현재와 같은 검증된 추천 성과로 이해하지 않도록 기본 추천 성과와 과거 보관 이력을 분리하는 편이 좋다. 이 리뷰에서는 데이터를 삭제하지 않았다.

서버 보관과 브라우저 식별자의 차이는 설명이 좋아졌으나 웹 로그인은 아직 없으므로 다른 기기에서도 이어 쓸 수 있다는 기대는 해결되지 않았다. 별도의 실제 Google 웹 로그인 검증이 필요하다. 과거 사용자/게임 데이터가 계정으로 자동 통합된다고 약속하면 안 된다.
