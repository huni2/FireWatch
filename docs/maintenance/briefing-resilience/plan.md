# 무료 브리핑 안정성 보완 계획

Gemini 기본 모델503 시 무료 보조모델 gemini-3.5-flash-lite를 시도한다. HTTP 요청은 영속 일별 카운터로 한국 날짜당 최대3회만 허용하며 기존 당일 실패 횟수도 초기 예산에서 차감한다. 429는 즉시 중지하고 유료 모델/사용자 키를 도입하지 않는다.

AI 장애에도 확보한 뉴스·지표의 기본 브리핑을 제공하고 자료 부족을 명시한다. 추천은 같은 브리핑과 포함 기사에서 검증해 보관하며 별도 Gemini 호출과 제공처 실패 회로를 사용하지 않는다. 적합한 추천0건은 정상 완료로 보관한다.

서버 기동10초 후 및 깨어 있는 동안5분마다 미완료 작업을 확인한다. 기존 DB 임대/재시도 시각/한도는 유지하고 휴면 중 실행을 보장하지 않는다. 정상·과거 브리핑과 사용자 알림 발송 기록은 보존한다.

로컬 HTTP·H2/PG 통합·일별 예산/동시성·기본 자료·추천 재사용·주기 실행을 검증하고 전체 빌드/CI 후 운영 배포·실제 보조모델/기본 브리핑 상태를 확인한다.
