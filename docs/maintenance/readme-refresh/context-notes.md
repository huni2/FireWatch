# 작성 근거

- 사용자 원칙은 무료 API 범위 운영이며 일반 사용자에게 API 키나 결제를 요구하지 않는 것이다. 직접 서버를 운영하는 개발자의 환경 설정과 구분한다.
- 서버132dfbf에 Gemini3.6 전환/FALLBACK 제한 복구를 배포했다. 이후 오늘 브리핑NORMAL을 확인했지만 추천503·환율3종누락은 남아 있다.
- 중복 Gemini 호출 제거, 추천 없음 정상 처리, 마지막 정상 환율의 기준일 표시, 환율 상세 오류 기록은 합의한 개선 방향이며 아직 구현된 것으로 쓰지 않는다.
- Android1.0.14/versionCode19는 준비된 로컬 AAB이며 Play 게시본으로 확정하지 않는다. 공개 다운로드는 GitHub API 결과와 대조한다.
- 루트 메모와 위키의 기존 미커밋 내용은 보존하고 이번 문서만 별도로 기록한다.
- GitHub releases API로 공개 최신 v1.0.11-android-preview 및 APK 링크를 확인했다. 앱 package.json의1.0.14, 배포 검증JSON의versionCode19와 대조했다. 로컬 링크·앵커31개, 코드블록 쌍, 기본모델과 앱버전 표기 일치 검사PASS. 문서만 변경해 앱/서버 빌드는 다시 실행하지 않는다.
- 이전 출시 상세는 mobile/README.md와 검증 문서로 연결하고 최상위 README의 누적 출시 설명·중복 상태 문단은 줄였다. Gemini3.6/복구 서버 변경에는 앱 재배포가 필요 없다는 범위도 명시했다.
