# 브리핑 장애 복구 계획

Gemini 503 이후 FALLBACK이 당일 완료로 고정되는 문제를 해결한다. 기존 DB 임대와 30/60분 간격·한국 날짜별 실패 3회 한도 안에서 복구한다. 429는 당일 중지한다.

오늘 FALLBACK만 동일 ID로 AI 내용을 복구하며 저장된 시세·뉴스·생성 시각을 유지한다. 정상/과거 브리핑은 수정하지 않는다. 추천 분석은 복구 후 수행하며 근거 검증은 유지한다. 오류 기록에는 허용한 안전한 코드만 남긴다.

단위·DB 통합 테스트로 복구, 실패 보존, 호출 제한, 429 중지, 추천 오류 구분을 확인하고 백엔드 빌드를 실행한다.

사용자 배포 요청에 따라 기본 모델과 Render Blueprint를 gemini-3.6-flash로 전환한다. 기존 GEMINI_MODEL=gemini-3.5-flash 환경변수도 클라이언트에서 공식 대체 모델로 정규화한다. 실제 HTTP 요청 경로를 로컬 서버로 검증하고 main 배포·CI·공개 health를 확인한다.
