# FireWatch — 현재 맥락

최신화: 2026-10-08. 기능 코드 `9667eb1` 기준이며 이후 문서 커밋은 기능 변경이 아니다. 이전 설계·운영 이력은 [[log]]와 `Decisions/` 디렉터리를 확인한다.

## 제품 정체성과 범위

시장 자료를 이해하고 개인 투자 기록의 구성을 점검하는 웹·Android 서비스다. 관심 기업·가격/차트·뉴스·저장 추천 근거를 내 보유 기록과 연결한다. 실제 주문·증권사 자동 연동·실시간 시세 서비스는 제공하지 않는다.

가상투자는 독립 연습 메뉴이고 순위는 게임 내부에 둔다. 새 게임의 가격·지표·뉴스·픽은 모두 시드 기반 가상 자료다. 실제 기업명 확대는 미적용이며 현재 게임 기업은 5개다.

기본 디자인은 라이트·오렌지, 웹 다크 모드는 선택형이다. 사용자 요청으로 기능·UI/UX·디자인 정밀 점검에 착수했으며, 개발 포트폴리오용 문서 최신화를 먼저 수행했다. 화면 개선은 아직 적용하지 않았다.

## 핵심 동작

- 포트폴리오 직접 등록·원금 비중·수집 시세 평가·분야/통화 집중·ETF 지수명 중복. 버전 충돌 검사와 변경 이력 저장.
- 홈 내 기업 점검: 관심/보유 기업 합치기, 근거 있는 후보와 기사·내 구성 맥락, 가격/뉴스 탐색 연결.
- 회사명 검색·분야별 시작 목록·저장 뉴스 날짜/키워드 검색. 전 시장 카탈로그나 전체 ETF 편입 분석은 아님.
- Google 계정 연결·기기별 세션·연결 해제. 사용자 웹 실제 로그인 성공 확인, Android 설치 왕복은 미검증.
- 문의·공지·첫 방문 안내. 문의/운영 정보는 서버 권한으로 보호.
- 가상게임 총액/체결 기록·턴 설명·손익·그래프·픽 직접 매수·주문 초기화·선택형 주간 순위.

## 운영 경계

수집은 DB lease·종류별 KST 하루 실패 한도3·제한된 재시도를 사용한다. 네트워크 호출 동안 저장 트랜잭션을 유지하지 않는다. 실패 시 마지막 정상 관측과 기록을 보존한다. 지수·환율 실제 수집 장애의 복구는 아직 확인하지 않았다.

운영 DB Hikari는 최대3·유휴0·유휴 반환60초. session pooler의 공유 연결 예산을 고려한다.

운영자는 검증된 Google 이메일과 기기 세션으로 확인한다. 서버 전용 OPERATOR_API_KEY는 예약 작업/운영 인증에만 사용하며 VITE_*·EXPO_PUBLIC_*에 넣지 않는다. 공개 SETTINGS_API_KEY는 운영자 권한 근거가 아니다. 웹 로그인과 Render/GitHub 운영 키 등록은 사용자가 완료했다.

수집 장애 전역 자동 배너는 제거됐다. 운영자 설정에서 직접 펼칠 때만 진단을 조회하며 감사 기록·제한된 재시도·운영자 푸시는 유지한다. 진단을 숨긴 것은 장애 복구가 아니다.
