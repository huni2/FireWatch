# 0010 — Gemini Search Grounding 대신 네이버 뉴스 검색 API로 실제 기사 링크를 제공한다

## 상태
채택

## 맥락

[[Next-Tasks]] BE-3에서 이미 확정한 대로, Gemini 3 계열은 무료 티어에서 Google Search Grounding 도구 자체의 일일 할당량이 0이라(3.7/2.5/3.5 세 모델 실측으로 확정) 브리핑에 "실제 뉴스 출처"를 넣을 방법이 없었다. 사용자가 "클릭하면 실제로 볼 수 있는" 관련 뉴스를 요청했고, 결제 전환은 이미 옵션에서 완전히 배제하기로 확정한 상태([[Next-Tasks]] BE-3, 2026-08-21).

## 결정

**네이버 검색 오픈API(뉴스 검색)**로 실제 기사 목록(제목+원문 링크+미리보기)을 매일 브리핑에 함께 저장한다. 검색어는 사용자가 설정에서 등록한 관심 키워드(`user_settings.interest_keywords`)를 쓰고, 없으면 "코스피 증시"를 기본값으로 쓴다.

- `briefing_news` 테이블 신설(BIGSERIAL PK + `briefing_id` 평문 FK — 이 프로젝트 기존 관례대로 JPA `@ManyToOne` 관계 매핑 없이 평면 엔티티로 둠).
- `NaverNewsApiClient`(client 패키지) → `NewsService`(NEWS_API 감사 이벤트) → `SchedulerJob`이 브리핑 저장 직후 호출, 실패해도 브리핑 자체는 이미 저장됐으니 스케줄러 실패로 안 침(금융 API·FCM과 동일한 논-패탈 패턴).
- 웹은 `RelatedNewsCard`로 새 카드 추가, 각 항목은 `target="_blank"`로 원문 링크 클릭 가능.

## 근거

- **네이버를 고른 이유** — 한국 증시 브리핑이라는 도메인에 가장 잘 맞고(한국어 뉴스), 개인 개발자도 무료로 가입 가능(client_id/secret 발급만), 하루 25,000회 무료인데 이 앱은 하루 1회만 쓰면 돼 압도적으로 여유 있음. 응답에 `originallink`(언론사 원문 URL)가 그대로 와서 "클릭하면 실제로 볼 수 있게"라는 요구사항과 정확히 맞아떨어짐.
- **JSON 컬럼 대신 별도 테이블** — `recommended_stocks`/`interest_keywords`는 쉼표 구분 문자열로 단순화했지만(Jackson 3 패키지 이동 리스크 회피, [[Decisions/0001-tech-stack-baseline]] 계열 판단), 뉴스는 항목마다 제목+링크+설명+발행일 4개 필드가 필요해 구분자 문자열로 욱여넣으면 파싱이 더 복잡해진다. 대신 `briefing_news`를 별도 테이블로 둬서(audit_logs·briefings·user_settings와 같은 패턴) 각 필드를 그대로 컬럼에 담았다 — JPA 관계 매핑(`@OneToMany`)은 여전히 안 쓰고 평문 FK만 써서 이 프로젝트의 "관계 매핑 회피" 기조는 유지.
- **Gemini 재검토 트리거는 그대로 둠** — 이 결정은 Gemini를 완전히 대체하는 게 아니라, 막혀있는 동안의 대안이다. Gemini 그라운딩이 나중에 풀리면 "AI 요약 텍스트 + 실제 뉴스 링크"를 함께 쓰는 것도 고려할 수 있다(상호 배타적이지 않음).

## 결과·트레이드오프

**얻는 것** — Gemini 상태와 무관하게 즉시 동작하는, 실제 클릭 가능한 뉴스 링크. AI 요약보다 오히려 "진짜 출처가 보인다"는 신뢰도 이점도 있음.

**감수하는 것**
- AI가 정리해주는 자연스러운 요약문이 아니라 검색 결과 그대로(제목+스니펫)라 Gemini만큼 매끄럽진 않음.
- 네이버 뉴스 검색은 네이버에 색인된 기사만 대상이라, 아주 로컬하거나 실시간 속보는 못 잡을 수 있음(이 앱의 "아침 브리핑" 용도엔 충분하다고 판단, 별도 검증 안 함).
- 새 외부 API 의존성 1개 추가(네이버 정책 변경 리스크) — 다만 무료 한도가 워낙 넉넉해 당장 문제될 가능성은 낮음.

## 재검토 트리거

- 네이버 검색 오픈API가 유료화되거나 뉴스 검색 엔드포인트를 없애면 → 다른 무료 뉴스 API(예: 카카오 다음 뉴스 검색) 재검토.
- Gemini Search Grounding 무료 할당량이 다시 열리면 → AI 요약과 실제 뉴스 링크를 함께 쓰는 조합 검토.
