# 0018. 가상 픽 근거·턴 복기·전용 그래픽

2026-10-07 사용자는 다음 턴 대기를 자신의 거래/뉴스/지표/픽이 연결되는 주마등처럼 만들고, 가상 픽 선정 이유와 직접 생성한 그래픽을 추가하기를 원했다.

GameSimulation.gamePicks는 기존 픽 순서를 그대로 유지하고 해당 시나리오 뉴스·이유·위험을 전달한다. 기술주/에너지 직접 당사자와 비교 후보를 구분하고, 나머지 시드 기반 관찰 후보는 수익 확률 순위처럼 설명하지 않는다. 이유가 없는 기존 응답에는 임의 근거를 채우지 않는다. 실제 뉴스 추천 근거 저장과 게임 메타데이터는 별개다.

priceDrivers는 현재 턴의 기존 가격 규칙에 쓰인 시장 노출·업종 영향·자산별 변동을 전달한다. 반올림 전 규칙 기여를 퍼센트로 설명하며 거래정지는 전부 0으로 표시한다. 기존 가격 식과 시드/DB/매매 규칙은 변경하지 않는다. 미래 시나리오나 시드를 보내지 않는다. 픽 선택은 다음 턴의 시나리오를 예측하지 않는다.

다음 턴 클릭은 서버 요청을 즉시 시작하고 그동안 확정된 직전 거래·픽만 복기한다. 서버 확정 이후 새 뉴스/가상 지표/내 자산 가격/넘긴 포지션 손익/지난 픽 이후 가격을 표시한다. 건너뛰기는 네트워크 요청을 취소하거나 재요청하지 않으며 이후 다시보기로 결과를 열 수 있다. 오류 시 연출을 닫고 기존 상태에서 오류를 표시한다. 끝 턴에 새 인덱스가 없으면 새 가격 연출을 만들지 않는다. 결과를 늦추는 타이머나 외부 생성 AI 호출은 없다. 다시보기 스냅샷은 해당 화면의 메모리에 보관하며 앱 재시작 후 복구는 이 구현에 포함하지 않는다. 매도 완료 자산의 후속 가격 변화는 관찰로 구분하며 보유 손익을 만들어내지 않는다.

imagegen 스킬의 built-in image_gen으로 불꽃 정찰대 마스코트를 새로 생성했다. shared/assets/firewatch-scout.png는 실제 투명 alpha PNG이며 웹/모바일 픽과 복기에 공용으로 사용한다. 최종 프롬프트와 생성 방식은 firewatch-scout.prompt.md에 저장했다. 앱 런타임에는 생성 API를 호출하지 않는다. 웹은 가벼운 등장/캐릭터 움직임을 적용하고 reduced-motion에서는 끈다.

검증: 게임 서비스 회귀, 픽/뉴스/원래 후보 일치, 실제 가격 변화와 driver 합 일치 및 거래정지, 매도 관찰·롱/숏 손익·픽·지표 계산. 360/1280px 브라우저에서 원본 그림/근거/위험, 대기 중 직전 로그, 건너뛰기 후 요청 유지·중복 진행 없음·재열기·지표/손익/가격 규칙 연결과 기존 매수 흐름 확인. 웹 빌드·린트 및 모바일 타입·린트·생성 이미지 포함 Android JS 번들 검증 통과. 실제 네이티브 화면과 운영 배포/서버 지연 시간 변화는 미검증이다.
