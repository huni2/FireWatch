# ADR 0014 — 독립 랜덤 턴제 게임과 오렌지 테마

날짜: 2026-10-07. 사용자가 게임은 별개의 가상투자게임이며 날짜가 랜덤이라고 명시했다. 시각 방향은 짙은 바탕 + 오렌지 포인트의 게임·시장 대시보드를 선택했다. ADR 0013의 시간순 투자 연습 정의를 정정한다.

**최종 사용자 확정(아래 과거 자료 설계보다 우선)**: 뉴스·지표·AI 픽·종목·가격을 모두 가상으로 생성한다. GameSimulation은 가상 회사 5개와 6개 시장 사건을 사용하고 세션 시드·턴 번호로 재현한다. 총 24턴이며 무작위 2030년 날짜는 게임 표기일 뿐이다. 가격 변화는 턴 순서·시장 방향·업종 영향·자산별 변동을 따른다. 픽은 시나리오 규칙이며 실제 AI 모델/투자 추천이 아니다. 새 게임의 모든 상태/주문/턴 진행에서 실제 뉴스·시세·AI API를 호출하지 않는다.

금액 미리보기는 응답에 포함된 가상 가격으로 웹/모바일이 즉시 계산하고 서버가 체결 시 단가·턴·잔고·수량·요청 ID를 검증한다. 서버에서 거래 내역을 반복 조회하던 부분도 같은 요청의 원장으로 재사용한다. Render 무료 서버의 첫 기동 대기는 별개이며 오래 기다리면 응답 대기 안내를 표시한다. 기존 과거 자료 세션은 이력을 삭제하지 않고 새 게임 시작 시 종료 보관하며 가상 세션을 만든다. 아래 가격 누락 방어는 기존 세션에 대한 호환 경로다.

새 게임은 최근 최대 90개 브리핑 날짜를 섞는다. 기존 세션 덱은 변경하지 않는다. 가격 숫자와 게임머니를 사용하는 독립 게임이며 실제 환산·수수료·세금·기업행사·공매도 증거금·사이드카·거래정지는 구현하지 않는다. 사용자에게 무작위 날짜와 게임 단위를 설명한다.

확정된 가격은 세션·턴·자산별 DB 스냅샷에 저장한다. 주문 미리보기와 체결은 같은 가격을 사용하고 예상 턴과 확인 단가를 검증한다. 요청 ID는 통신 실패 재시도에도 유지한다. 거래 영수증에 수량·단가·총액을 반환한다. 가격 자료가 없으면 평가액과 전체 수익률은 null이며 0원으로 대체하지 않는다. 다음 턴의 보유 자산 가격이 없으면 현재 턴을 유지한다. 현재 턴에서 정리하거나 재시도할 수 있다. 개별 종목은 기존 6개월 조회 범위 안에서 해당 날짜 이전 7일 이내 종가만 허용한다.

AI 픽은 해당 브리핑에 저장된 후보만 표시한다. 빈 후보/FALLBACK의 이유를 항상 보여주며 임의 후보를 생성하지 않는다. 이름 검색 후 티커를 직접 선택한다. 첫 턴 대비 코스피는 랜덤 게임의 비교 수치이며 실제 기간 벤치마크로 표현하지 않는다.

색상·표면·radius를 shared/design-tokens.json에 둔다. 웹 전체 테마·메뉴·포트폴리오 첫 화면과 웹/모바일 게임에 적용한다. 모바일의 다른 화면 전체 다크모드 전환은 APP-14 후속이다.

ThreeUI 커뮤니티 ModernToggle을 MIT 조건으로 가져오고 controlled/disabled와 축소된 오렌지 스타일을 추가한다. 원문 LICENSE 및 배포 고지를 유지한다. WebGL/Three.js는 추가하지 않는다. OriginKit은 공개 화면 참고만 적용했으며 로그인/API 키로 얻어야 하는 코드는 취득하거나 복사하지 않았다.

운영 배포는 수행하지 않았다. 기존 additive SQL에 game_price_snapshots가 추가되어 backend 배포 전에 PostgreSQL 스테이징 검증이 필요하다. 비용 0원 및 OpenSearch 보류 결정은 유지한다.

## 2026-10-07 추가 결정

최신 사용자 요구가 우선한다. 기본 화면은 라이트 + 오렌지다. 웹은 저장된 다크 선택을 유지하고 모바일은 전체 주요 화면/시트/헤더/차트/토스트를 라이트 토큰으로 통일한다. 공유 간격·타이포 토큰도 추가한다. 위의 과거 자료 게임/다크 기본 설명은 이전 설계 이력이다.

가상 사건은 시드·턴으로 결정되며 새로고침으로 바뀌지 않는다. 가상 사이드카는 한 턴 동안 지수 주문만 제한한다. 개별 종목·원자재·달러는 허용한다. 가상 종목 거래정지는 그 종목의 매매를 막고 직전 평가 가격을 유지한다. 다음 턴에 해당 제한은 해제되며 새로운 사건이 다시 발생할 수 있다. 실제 거래소 규정을 재현한 것이 아닌 게임 전용 규칙으로 표시한다.

턴 손익은 직전 턴 보유 수량 × 이번/직전 가격 차이로 설명한다. 이번 턴에 매도한 자산과 음수 공매도 수량도 포함한다. 수수료 0·동일 턴 고정 단가이므로 그 기여 합계가 총 턴 변화액이다. 미확정 가격은 null로 유지한다.

SSE는 게임 계산이나 체결 속도를 개선하지 않아 도입하지 않는다. 완결된 POST 응답에 상태/사건/손익을 함께 반환하고, 턴 진행의 원장은 한 번만 읽는다. 장시간 AI 생성/뉴스 수집 완료를 구독할 필요가 생길 때 별도로 검토한다. Render 콜드스타트는 별개다.
