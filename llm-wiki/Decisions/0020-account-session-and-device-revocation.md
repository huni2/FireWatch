# 0020. 연동 계정에 만료·폐기 가능한 세션을 요구한다.

2026-10-07. 운영 리뷰 후속 보안 보강. ADR 0012의 연동 계정 인증 방식만 대체하며 익명 사용은 유지한다.

기기 ID는 Google 계정 인증을 대신할 수 없다. Google ID 토큰 검증 후 256비트 무작위 로그인 세션을 발급하며 서버는 SHA-256 해시와 기기·계정·30일 만료만 저장한다. 재로그인하면 해당 기기의 이전 세션을 폐기한다. 만료 시 Google로 다시 로그인하며 자동 연장·refresh 토큰은 발급하지 않는다. 모바일은 Expo SecureStore에 보관한다.

계정에 연결된 설정·포트폴리오·운영자 등록과 계정 관리 API는 기기와 일치하는 유효한 Bearer 토큰을 요구한다. 익명 기기의 설정·포트폴리오는 기존 UUID 방식이며 이것은 정식 계정 인증을 제공하지 않는다. 공개 뉴스·시세·추천은 로그인 없이 조회한다. 기존 세션 없는 연동 기기는 재로그인이 필요하다. 다른 Google 계정으로 연결된 기기 ID를 가져갈 수 없다.

연결 기기 목록은 원래 UUID 대신 해시 기반 식별자·연결일·현재 기기 여부를 제공한다. 자기 계정의 기기만 해제할 수 있고 세션과 연결을 함께 제거한다. 로그아웃도 현재 기기의 연결과 세션을 폐기하지만 공유 설정·포트폴리오는 보존한다. 계정 완전 삭제는 모든 세션과 연결·공유 자료를 삭제한다. 변동 작업은 비밀값을 가린 AUTH 감사로그를 남긴다.

Android 로그인 실기기 왕복과 푸시 구독의 기기별 해제는 별도 검증·후속 과제다. SecureStore를 추가했으므로 새 네이티브 빌드가 필요하며 JS 번들 export만으로 실기기 보안 저장소 검증을 대신하지 않는다.
