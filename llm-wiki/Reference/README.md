# Reference

이 프로젝트의 요구사항 정본은 코드 옆의 위키가 아니라 **원본 문서 3종**이다:

- `../../docs/specs/프로젝트 기획 및 시스템 명세서.pdf` — 기능 요구사항(FR-01~FR-07), 감사로그 DB 스키마, 아키텍처 구성도, 기술 스택.
- `../../docs/specs/UI 디자인 프레임워크 추천 제안서.pdf` — 웹/모바일 UI 프레임워크 비교.
- `../../docs/specs/UI 디자인 참고 사이트 및 애니메이션 가이드.pdf` — 벤치마킹 사이트, 애니메이션 원칙.

**문제·요구사항을 서술할 때 이 세 문서에 없는 내용을 "요구사항"으로 새로 지어내지 않는다.** 명세서와 다른 판단을 할 때는 [[../Decisions|Decisions]]에 ADR로 근거를 남긴다.

sympo-studio의 `Reference/field-experience.md`(실무 경험 정본)에 해당하는 문서는 FireWatch에는 없다 — 이 프로젝트는 처음부터 문서 기반으로 시작했기 때문이다.
